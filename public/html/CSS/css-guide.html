Cascading Style Sheets - Styling the Web

1) Introduction to CSS

What is CSS?

CSS (Cascading Style Sheets) is used to style and layout web pages.

Main Features:

  • ✅ Style - Make webpages beautiful
  • ✅ Responsive Design - Adapt to different screen sizes
  • ✅ Animations - Create 2D and 3D animations
  • ✅ Rotation & Effects - Transform elements
  • ✅ Fast Development - Global CSS for consistency
💡 Key Point: HTML is required for structure, CSS allows you to style that structure beautifully.

CSS Syntax

h1 {
    color: red;
}
  • Selector: h1 - Targets the element
  • Property: color - What to style
  • Value: red - How to style it

2) History of CSS

Year Version Details
1996 CSS 1 First introduction of CSS
1998 CSS 2 Second version with positioning
1999-Present CSS 3 Modular approach, continuously evolving
📌 Note: CSS3 is still under active development with new features being added regularly.

3) Ways to Implement CSS

Method 1: Inline Styles

Apply styles directly to HTML elements using the style attribute.

<h1 style="color: green; background-color: blue;">Hello</h1>
Demo - Inline Style

This uses inline styling

⚠️ Drawback: Not reusable, harder to maintain, mixes HTML and CSS.

Method 2: Internal/Embedded Styles (In-Page)

Use the <style> tag inside the <head> section.

<head>
    <style>
        h1 {
            color: green;
        }
    </style>
</head>
✅ Benefit: Styles entire page, better than inline but still limited to one page.

Method 3: External Stylesheet (BEST PRACTICE)

Link to an external CSS file using the <link> tag.

<head>
    <link rel="stylesheet" href="index.css">
</head>
✅ Best Practice: Reusable across multiple pages, easy to maintain, separates concerns.

Google Fonts

You can import custom fonts from Google Fonts:

<link href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap" rel="stylesheet">

/* In CSS */
body {
    font-family: 'Roboto', sans-serif;
}

4) CSS Selectors

CSS selectors are used to "find" (or select) the HTML elements you want to style.

1. Element Selector

Selects all elements of a specific type.

h1 {
    color: green;
}

/* Multiple elements */
h1, h2, p {
    color: green;
}
Demo

All paragraph elements can be styled

Like this example

2. Class Selector (.)

Selects elements with a specific class attribute. Classes are reusable and can be applied to many elements.

.classname {
    color: blue;
}

/* HTML */
<p class="classname">Styled with class</p>
💡 Prefix: Use a dot (.) before the class name in CSS.

3. ID Selector (#)

Selects a single element with a specific ID. IDs should be unique per page.

#main-title {
    color: red;
}

/* HTML */
<h1 id="main-title">Main Title</h1>
📌 Standard: ID should only be used once per page. Use classes for reusable styles.

4. Universal Selector (*)

Selects ALL elements on the page.

* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

5. Attribute Selector ([attribute])

Selects elements based on their attributes.

a[target] {
    background-color: yellow;
}

a[target="_blank"] {
    color: red;
}

input[type="text"] {
    border: 2px solid blue;
}
Demo
Link with target attribute

Selector Specificity (Priority)

When multiple selectors target the same element, specificity determines which style wins:

Priority Selector Type Example
1 (Highest) Inline Styles style="color: pink;"
2 IDs #navbar
3 Classes, Pseudo-classes, Attributes .test, :hover, [href]
4 (Lowest) Elements, Pseudo-elements h1, ::before
📌 Remember: Element selector has the least priority, ID selector has more priority than class selector.

Important Properties

inherit

Inherits property from parent element.

body {
    font-size: 20px;
}

h1 {
    font-size: inherit; /* Gets 20px from body */
}

!important

Overrides all other declarations (use sparingly!).

p {
    color: blue !important;
}
⚠️ Warning: Avoid using !important too much as it makes debugging difficult.

6) Box Model

Every HTML element is considered a box with the following structure:

MARGIN
BORDER
PADDING
CONTENT

Order (Inside to Outside):

  1. Content - The actual content (text, images)
  2. Padding - Space around content, inside border
  3. Border - Border around padding
  4. Margin - Space outside border

Margin

/* Individual sides */
margin-top: 20px;
margin-right: 15px;
margin-bottom: 20px;
margin-left: 15px;

/* Shorthand */
margin: 20px 15px 20px 15px; /* top right bottom left */
margin: 20px 15px; /* top/bottom left/right */
margin: 20px; /* all sides */

Margin Collapsing

When two vertical margins meet, they collapse into one. The larger margin wins.

Margin: auto (Centering)

.center {
    width: 50%;
    margin: 0 auto; /* Centers horizontally */
}

Padding

/* Individual sides */
padding-top: 20px;
padding-right: 15px;
padding-bottom: 20px;
padding-left: 15px;

/* Shorthand (same as margin) */
padding: 20px 15px 20px 15px;
padding: 20px 15px;
padding: 20px;

Border

/* Individual properties */
border-width: 2px;
border-style: solid; /* solid, dashed, dotted, double */
border-color: orange;

/* Shorthand */
border: 2px solid blue;

Width and Height

By default, width is 100% for block elements.

div {
    width: 200px;
    height: 200px;
}
⚠️ Important: Width and height only apply to content. Padding and border are added on top!

box-sizing Property

Controls how width and height are calculated.

/* Default - width/height applies to content only */
box-sizing: content-box;

/* Better - width/height includes padding and border */
box-sizing: border-box;

content-box (default)

Width = content only

Total = width + padding + border

100px content
Total: 150px

border-box (recommended)

Width = content + padding + border

Total = width

Includes all
Total: 150px
✅ Best Practice: Set box-sizing: border-box; on all elements using the universal selector.

Browser Default Margins

Browsers add default margins to elements. Remove them with:

body {
    margin: 0;
}

/* Or for all elements */
* {
    margin: 0;
    padding: 0;
}

9) Position Property

Position allows you to place elements in various positions in the DOM.

position: static (Default)

Normal document flow. Default positioning for all elements.

div {
    position: static; /* Default */
}

position: relative

Positioned relative to its normal position. Leaves a gap in original position.

.relative {
    position: relative;
    top: 20px;
    left: 30px;
}
Demo - Relative Positioning
Normal Box
Relative Box (moved from original)
Normal Box
📌 Key: Uses top, right, bottom, left to move from original position.

position: absolute

Positioned relative to nearest positioned ancestor (or document). Removed from normal flow.

.parent {
    position: relative;
}

.child {
    position: absolute;
    top: 10px;
    right: 10px;
}
Demo - Absolute Positioning
Parent with relative position
Absolute Child
💡 Tip: Parent needs position: relative for child to be positioned relative to it.

position: fixed

Fixed relative to viewport. Stays in place when scrolling.

.navbar {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
}
📌 Use Case: Navigation bars, floating buttons, headers that stay visible while scrolling.

position: sticky

Combination of relative and fixed. Sticks when scrolling past it.

.sticky-header {
    position: sticky;
    top: 0;
}
💡 New Feature: Sticky is relatively new but well-supported in modern browsers.

z-index

Controls stacking order of positioned elements. Higher values appear on top.

.back {
    position: relative;
    z-index: -1; /* Behind */
}

.front {
    position: relative;
    z-index: 1; /* In front */
}
⚠️ Important: z-index only works on positioned elements (not static).

10) Background Images

Background Properties

div {
    background-image: url("image.jpg");
    background-size: cover; /* or contain, 100%, etc. */
    background-repeat: no-repeat;
    background-position: center center; /* or 20px 10px, left top */
    background-attachment: fixed; /* or scroll */
}

background-size Values:

  • cover - Scales image to cover entire container (may crop)
  • contain - Scales image to fit inside container (may show gaps)
  • 100% - Specific size
  • auto - Original size

Shorthand:

background: url("img.jpg") no-repeat center center / cover;

11) Size and Units

A) CSS Units

Unit Type Description
px Absolute Pixels - fixed size
% Relative Percentage of parent element
em Relative Relative to parent font-size
rem Relative Relative to root (html) font-size
vh Viewport 1% of viewport height
vw Viewport 1% of viewport width
cm, mm Absolute Centimeters, millimeters (rarely used)

B) Where Units Apply

Units can be used for:

  • font-size
  • padding, border, margin
  • width, height
  • top, bottom, left, right

C) Unit Categories

1. Absolute Length

Fixed size, ignores user settings. px, cm, mm

2. Viewport Length

Adjusts based on viewport size. vh, vw, vmin, vmax

.full-height {
    height: 100vh; /* Full viewport height */
}

.half-width {
    width: 50vw; /* Half viewport width */
}

3. Font-Relative Length

Adjusts to font size. em, rem

html {
    font-size: 16px; /* Base size */
}

p {
    font-size: 1.5rem; /* 24px (16 * 1.5) */
    padding: 2em; /* 48px (24 * 2) - relative to element's font-size */
}

em

Relative to parent's font-size

Can compound (nest deeply = bigger sizes)

rem (Recommended)

Relative to root (html) font-size

More predictable, doesn't compound

12) Responsive Web Design

Tool 1: Viewport Meta Tag

Essential for responsive design. Add to <head>:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Viewport Properties:

  • width=device-width - Adapts to device width
  • initial-scale=1.0 - Initial zoom level
  • user-scalable=yes - Allow zoom (yes/no)
  • maximum-scale=2.0 - Maximum zoom level
  • minimum-scale=1.0 - Minimum zoom level
📌 Note: This adjusts website to viewport but doesn't change design.

Tool 2: Media Queries

Change design based on screen size and device characteristics.

Basic Syntax:

@media (min-width: 768px) {
    /* Styles for screens 768px and wider */
    .container {
        width: 750px;
    }
}

Common Breakpoints:

/* Mobile First Approach */
/* Mobile (default) */
.container {
    width: 100%;
}

/* Tablet */
@media (min-width: 768px) {
    .container {
        width: 750px;
    }
}

/* Desktop */
@media (min-width: 1024px) {
    .container {
        width: 1000px;
    }
}

/* Large Desktop */
@media (min-width: 1200px) {
    .container {
        width: 1170px;
    }
}

AND Operator (Multiple Conditions):

@media (min-width: 768px) and (max-width: 1024px) {
    /* Styles for tablets only */
}

OR Operator (Comma):

@media (max-width: 480px), (orientation: landscape) {
    /* Mobile OR landscape */
}

Orientation:

@media (orientation: landscape) {
    /* Landscape mode */
}

@media (orientation: portrait) {
    /* Portrait mode */
}
✅ Best Practices:
  • 1. Arrange media queries from small to large (mobile-first)
  • 2. Find natural breaking points for your design
  • 3. Place all media queries at the bottom of your CSS

14) Flexbox Layout

What is Flexbox?

CSS Flexbox is a one-dimensional layout pattern that makes it easy to design flexible and responsive layouts.

Benefits:

  • ✅ Flexible arrangement of items
  • ✅ Easy spacing and alignment
  • ✅ Control order of items
  • ✅ Bootstrap 4 & 5 built on Flexbox

Terminology

  • Flex Container - Parent element with display: flex
  • Flex Items - Direct children of flex container
  • Main Axis - Primary direction (default: left to right)
  • Cross Axis - Perpendicular to main axis (default: top to bottom)
  • Main Size - Width along main axis
  • Cross Size - Height along cross axis

Flex Container Properties

1. display

display: flex; /* Block-level flex container (full width) */
display: inline-flex; /* Inline flex container (fits content) */

2. flex-direction

Controls the direction of main axis.

flex-direction: row; /* Default - left to right */
flex-direction: row-reverse; /* right to left */
flex-direction: column; /* top to bottom */
flex-direction: column-reverse; /* bottom to top */

3. flex-wrap

Controls whether items wrap to new lines.

flex-wrap: nowrap; /* Default - single line (may overflow) */
flex-wrap: wrap; /* Wrap to next line */
flex-wrap: wrap-reverse; /* Wrap to previous line */

4. flex-flow (Shorthand)

Combines flex-direction and flex-wrap.

flex-flow: row wrap; /* direction wrap */
flex-flow: column nowrap;

5. justify-content

Aligns items along main axis (horizontal by default).

justify-content: flex-start; /* Default - start of main axis */
justify-content: flex-end; /* End of main axis */
justify-content: center; /* Center */
justify-content: space-between; /* Equal space between items */
justify-content: space-around; /* Equal space around items */
justify-content: space-evenly; /* Equal space everywhere */

6. align-items

Aligns items along cross axis (vertical by default).

align-items: stretch; /* Default - stretch to fill */
align-items: flex-start; /* Start of cross axis */
align-items: flex-end; /* End of cross axis */
align-items: center; /* Center */
align-items: baseline; /* Align baselines */

7. align-content

Aligns flex lines (only works with multiple lines / flex-wrap).

align-content: stretch; /* Default */
align-content: flex-start;
align-content: flex-end;
align-content: center;
align-content: space-between;
align-content: space-around;

Flex Item Properties

1. order

Changes the order of items. Default is 0.

.item-1 { order: 2; }
.item-2 { order: 1; }
.item-3 { order: 3; }

2. flex-grow

Defines how much an item should grow relative to others. Default is 0 (no growth).

.item { flex-grow: 1; } /* Each item grows equally */
.item-special { flex-grow: 2; } /* Grows 2x more */

3. flex-shrink

Defines how much an item should shrink. Default is 1.

.item { flex-shrink: 1; } /* Can shrink */
.no-shrink { flex-shrink: 0; } /* Won't shrink */

4. flex-basis

Defines initial size before growing/shrinking. Default is auto.

.item { flex-basis: 200px; }
.item { flex-basis: 50%; }

5. flex (Shorthand)

Combines flex-grow, flex-shrink, and flex-basis.

flex: 1; /* flex-grow: 1, flex-shrink: 1, flex-basis: 0 */
flex: 0 1 auto; /* grow shrink basis */
flex: 2 1 200px;

6. align-self

Overrides align-items for individual items.

.item {
    align-self: flex-start; /* or flex-end, center, stretch */
}

15) CSS Grid Layout

What is CSS Grid?

CSS Grid is a two-dimensional layout system for creating complex grid-based layouts.

Basic Usage:

.container {
    display: grid;
    grid-template-columns: 200px 100px 20% 1fr;
    grid-template-rows: 100px auto;
    gap: 10px;
}

Grid Properties

grid-template-columns

Defines column structure.

grid-template-columns: 200px 200px 200px; /* 3 columns, 200px each */
grid-template-columns: 1fr 1fr 1fr; /* 3 equal columns */
grid-template-columns: 1fr 2fr 1fr; /* Middle column is 2x wider */
grid-template-columns: repeat(3, 1fr); /* Shorthand for 3 equal columns */
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); /* Responsive */

grid-template-rows

Defines row structure.

grid-template-rows: 100px 200px 100px;
grid-template-rows: auto 1fr auto;

gap (or grid-gap)

Space between grid items.

gap: 10px; /* Same for rows and columns */
gap: 10px 20px; /* row-gap column-gap */
row-gap: 10px;
column-gap: 20px;

fr Unit

1fr represents one fraction of available space.

grid-template-columns: 1fr 2fr;
/* First column gets 1/3, second gets 2/3 */

Grid vs Flexbox

Flexbox

  • One-dimensional (row OR column)
  • Content-first (items control layout)
  • Best for components, small layouts
  • Simpler for linear layouts

Grid

  • Two-dimensional (rows AND columns)
  • Layout-first (grid controls placement)
  • Best for page layouts, complex grids
  • More powerful for 2D layouts

16) General CSS Knowledge & Tips

1. Grouping Rules

Group selectors with same properties:

h1, h2, h3 {
    color: red;
    font-family: Arial;
}

2. Multiple Classes

Apply multiple classes to one element:

<div class="box large primary">Content</div>
📌 Note: If classes clash, the one defined LAST in CSS file wins (not HTML order).

3. Class vs ID

  • Class: Reusable, use for styling, can be used multiple times
  • ID: Should be unique, use for JavaScript targeting, not primarily for styling
✅ Best Practice: Use classes for styling. IDs have performance implications and less flexibility.

4. !important (Use Sparingly)

Overwrites all other selectors:

p {
    color: blue !important;
}
⚠️ Warning: Avoid using !important. It makes debugging difficult and breaks cascade.

5. Float & Clear

Float moves element left or right (older technique, use Flexbox/Grid instead).

.left {
    float: left;
}

.clearfix {
    clear: both; /* Clears floats */
}

6. Useful Properties

cursor

button {
    cursor: pointer;
}

.disabled {
    cursor: not-allowed;
}

box-shadow

.card {
    box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);
}

border-radius

.rounded {
    border-radius: 10px;
}

.circle {
    border-radius: 50%;
}

opacity

.transparent {
    opacity: 0.5; /* 0 = invisible, 1 = fully visible */
}

17) CSS Best Practices

✅ DO's

  • ✅ Use external stylesheets
  • ✅ Use meaningful class names
  • ✅ Follow mobile-first approach
  • ✅ Use CSS variables for consistency
  • ✅ Organize CSS logically (layout, components, utilities)
  • ✅ Use shorthand properties when possible
  • ✅ Set box-sizing: border-box globally
  • ✅ Use Flexbox and Grid for layouts
  • ✅ Comment your code for clarity
  • ✅ Validate your CSS

❌ DON'Ts

  • ❌ Don't use inline styles excessively
  • ❌ Don't overuse !important
  • ❌ Don't use IDs for styling
  • ❌ Don't create overly specific selectors
  • ❌ Don't forget vendor prefixes when needed
  • ❌ Don't use floats for layout (use Flexbox/Grid)
  • ❌ Don't ignore browser compatibility
  • ❌ Don't write repetitive code (DRY principle)

🎯 Performance Tips

  • 🚀 Minimize CSS file size
  • 🚀 Avoid expensive properties (box-shadow on many elements)
  • 🚀 Use CSS instead of images when possible
  • 🚀 Optimize animations (use transform and opacity)
  • 🚀 Load critical CSS inline, defer non-critical
  • 🚀 Use CSS Grid/Flexbox instead of complex floats
