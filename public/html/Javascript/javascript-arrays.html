📚 JavaScript Arrays

Complete Guide to Arrays and Array Methods

📚 Introduction to Arrays

In JavaScript, an Array is a global object that is used in the construction of arrays; which are high-level, list-like objects. Unlike arrays in languages like C, JavaScript arrays are dynamic and can store elements of different types within the same instance.

The Array Mental Model

Think of an array as a continuous sequence of memory slots where each slot is indexed. While JavaScript engines optimize "dense" arrays for performance, they are technically objects where the indices are just property names.

Technical Summary

  • 📝 Indexed-Based: Access time is O(1) when the index is known.
  • 📝 Dynamic Sizing: Automatically reallocates memory as it grows.
  • 📝 Iterable: Implements the iterator protocol for use with for...of.

🔑 High-Fidelity Characteristics

To master arrays, you must understand their Object-based nature and how they interact with memory.

  • ✅ Zero-indexed: Direct memory offset access.
  • ✅ Dynamic Pointer Tracking: The length property is not a count; it is an unsigned 32-bit integer that is always numerically greater than the highest index.
  • ✅ Prototype Linkage: All arrays delegate to Array.prototype, granting access to the global method suite.
  • ✅ Holey vs Packed: V8 optimizes arrays that have no gaps (Packed) significantly better than those with holes (Holey).

🔨 Creation Design Patterns

Method 1: Array Literal (The Gold Standard)

Senior Perspective: Use literals for 99% of cases. They are declarative, easy for the engine to optimize as 'Packed' arrays, and avoid the "single argument" pitfall of the constructor.

Definition: Using brackets [] is the most common and performant way to initialize an array. It creates a dense array with an immutable length at the split-second of creation.

const fruits = ["Apple", "Banana", "Orange"]; const numbers = [1, 2, 3, 4, 5]; const mixed = [1, "hello", true, {name: "John"}];

Method 2: Array Constructor via new

Definition: Calling the Array class directly. While useful for creating specific lengths, it can lead to "Sparse Arrays" (holes in memory) if used incorrectly.

const arr = new Array("Mango", "Grape"); const reserved = new Array(5); // Creates 5 empty slots (Sparse Array)
⚠️ Memory Note: new Array(5) does not fill the array with undefined; it creates 5 holes in memory. Most array methods like map() will skip these holes.

➕➖ Stack & Queue Mechanics

JavaScript arrays function as both **Stacks (LIFO)** and **Queues (FIFO)**.

Performance Deep-Dive: Big O

  • push/pop: O(1) - Constant time. No elements need to be shifted.
  • shift/unshift: O(n) - Linear time. All remaining elements must be re-indexed in memory.

Optimization Tip: Avoid unshift in large loops; it's a major performance bottleneck.

🔍 Search & Transformation (Modern)

let fruits = ["Apple", "Banana", "Orange"]; // Array.prototype.flat() - Flattening nested structures const nested = [1, [2, [3, 4]]]; console.log(nested.flat(2)); // [1, 2, 3, 4] // Array.prototype.flatMap() - Map + Flat in one pass const phrases = ["hello world", "the news"]; const words = phrases.flatMap(x => x.split(" ")); // ["hello", "world", "the", "news"]

TypedArrays: Low-Level Performance

For high-performance graphics, audio processing, or large numeric datasets, JavaScript provides TypedArrays. Unlike standard arrays, these are fixed-length views over a raw memory buffer (ArrayBuffer), offering predictable performance and no garbage collection overhead for internal elements.

const buffer = new ArrayBuffer(16); // 16 bytes const int32View = new Int32Array(buffer); // View as signed 32-bit integers

🔗 concat() - Join Arrays

The concat() method joins two or more arrays and returns a new array without changing existing arrays.

const arr1 = [1, 2, 3]; const arr2 = [4, 5, 6]; const arr3 = [7, 8, 9]; const joined = arr1.concat(arr2, arr3); console.log(joined); // [1, 2, 3, 4, 5, 6, 7, 8, 9]

📋 copyWithin() - Copy Elements

Copies array elements to another position, overwriting existing values.

// Syntax: array.copyWithin(target, start, end) const arr = [1, 2, 3, 4, 5]; arr.copyWithin(0, 3, 5); // Copy elements from index 3-5 to index 0 console.log(arr); // [4, 5, 3, 4, 5]

🔑 entries() - Key/Value Pairs

Returns an Array Iterator with key/value pairs.

const fruits = ["Banana", "Orange", "Apple"]; const iterator = fruits.entries(); for (let [index, value] of iterator) { console.log(index, value); } // 0 "Banana" // 1 "Orange" // 2 "Apple"

✔️ every() - Test All Elements

Returns true if all elements pass the test, false otherwise.

const ages = [32, 33, 19, 40]; const allAdults = ages.every(age => age >= 18); console.log(allAdults); // true const ages2 = [32, 33, 16, 40]; const allAdults2 = ages2.every(age => age >= 18); console.log(allAdults2); // false

🎨 fill() - Fill with Value

Fills elements with a static value.

// Syntax: array.fill(value, start, end) const arr = [1, 2, 3, 4, 5]; arr.fill(0, 2, 4); // Fill with 0 from index 2 to 4 console.log(arr); // [1, 2, 0, 0, 5]

🔄 forEach() - Declarative Iteration

Definition: A declarative method to iterate over elements. Unlike a for loop, forEach cannot be stopped with break or continue and it returns undefined.

When to avoid: If you need to stop early or transform data into a new array. Use for...of for stopping early, and map() for transformations.
const prices = [19.99, 29.99, 39.99]; prices.forEach((price, index) => { console.log(`Item ${index + 1}: $${price}`); });

🗺️ map() - Immutability & Transformation

Definition: Creates a shallow copy of your array, applying a transformation to every element. This follows functional programming principles where the original array remains untouched (Immutable).

const prices = [10, 20, 30]; const withTax = prices.map(price => price * 1.1); console.log(withTax); // [11, 22, 33]

🔍 filter() - Select Elements

Creates a new array with elements that pass the test.

const ages = [15, 22, 17, 30, 16, 25]; const adults = ages.filter(age => age >= 18); console.log(adults); // [22, 30, 25] // Remove duplicates const numbers = [1, 2, 3, 2, 4, 1, 5]; const unique = numbers.filter((item, index, arr) => arr.indexOf(item) === index ); console.log(unique); // [1, 2, 3, 4, 5]

🎯 find() & findIndex()

find() returns the first element that passes the test. findIndex() returns its index.

const users = [ {id: 1, name: "John"}, {id: 2, name: "Jane"}, {id: 3, name: "Bob"} ]; const user = users.find(u => u.id === 2); console.log(user); // {id: 2, name: "Jane"} const index = users.findIndex(u => u.name === "Bob"); console.log(index); // 2

📊 reduce() - The Accumulator Pattern

The Mechanics: reduce transforms an array into literally anything (an object, a number, a string, or even a new array). It is the Swiss Army Knife of functional programming.

Interview Tip: How it works

The callback receives four arguments: Accumulator (the running total), Current Value, Current Index, and the Source Array.

// Engineering Example: Complex Data Grouping const items = [ { category: 'tech', val: 100 }, { category: 'life', val: 50 }, { category: 'tech', val: 200 } ]; const totals = items.reduce((acc, item) => { acc[item.category] = (acc[item.category] || 0) + item.val; return acc; }, {}); // Result: { tech: 300, life: 50 }

// slice() - doesn't change original let fruits = ["Apple", "Banana", "Orange", "Mango"]; let citrus = fruits.slice(2, 4); console.log(citrus); // ["Orange", "Mango"] console.log(fruits); // Original unchanged // splice() - modifies original let items = ["a", "b", "c", "d", "e"]; let removed = items.splice(2, 2); // Remove 2 from index 2 console.log(removed); // ["c", "d"] console.log(items); // ["a", "b", "e"] // Insert with splice items.splice(2, 0, "x", "y"); // Insert at index 2 console.log(items); // ["a", "b", "x", "y", "e"]

🔢 sort() - Sort Array

// Sort numbers let numbers = [40, 100, 1, 5, 25]; numbers.sort((a, b) => a - b); // Ascending console.log(numbers); // [1, 5, 25, 40, 100] numbers.sort((a, b) => b - a); // Descending console.log(numbers); // [100, 40, 25, 5, 1] // Sort strings let names = ["John", "Alice", "Bob"]; names.sort(); console.log(names); // ["Alice", "Bob", "John"] // Sort objects let products = [ {name: "Laptop", price: 1000}, {name: "Phone", price: 500}, {name: "Tablet", price: 750} ]; products.sort((a, b) => a.price - b.price); console.log(products); // Sorted by price

🔄 reverse() - Reverse Array

const numbers = [1, 2, 3, 4, 5]; numbers.reverse(); console.log(numbers); // [5, 4, 3, 2, 1]

🔗 join() - Array to String

const words = ["Hello", "World"]; console.log(words.join(" ")); // "Hello World" console.log(words.join("-")); // "Hello-World" const path = ["home", "user", "documents"]; console.log(path.join("/")); // "home/user/documents"

🎯 Set Object - Unique Values

Set stores unique values and automatically removes duplicates.

// Remove duplicates let numbers = [1, 2, 3, 2, 4, 1, 5]; let unique = [...new Set(numbers)]; console.log(unique); // [1, 2, 3, 4, 5] // Set operations let tags = new Set(); tags.add("javascript"); tags.add("python"); tags.add("javascript"); // Duplicate, won't be added console.log(tags.size); // 2 console.log(tags.has("python")); // true tags.delete("python"); console.log(tags.size); // 1 // Iterate tags.forEach(tag => console.log(tag));

🏭 Array.from() - Create Array

Creates a new array from an iterable or array-like object.

// From string const str = "hello"; const chars = Array.from(str); console.log(chars); // ["h", "e", "l", "l", "o"] // Remove duplicates const numbers = [1, 2, 3, 3, 4, 4, 5]; const unique = Array.from(new Set(numbers)); console.log(unique); // [1, 2, 3, 4, 5]

📦 Array Types

Dense Array

Each element contains a value.

const dense = [1, 2, 3, 4, 5];

Sparse Array

Some elements are missing (undefined).

const sparse1 = [1, , , 4]; // Empty slots const sparse2 = new Array(5); // 5 empty slots const sparse3 = [1, 2, 3]; sparse3.length = 5; // Creates empty slots

Scalar Array

Contains same data type.

// Compare scalar arrays const arr1 = [1, 2, 3, 4, 5]; const arr2 = [1, 2, 3, 4, 5]; const isEqual = arr1.length === arr2.length && arr1.every((val, idx) => val === arr2[idx]); console.log(isEqual); // true
