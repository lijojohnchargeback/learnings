📚 What is JavaScript?

JavaScript is a high-level, object-oriented, multi-paradigm programming language that supports both imperative and declarative programming styles.

Key Facts

  • 📅 Created: May 1995 by Brendan Eich
  • 🏷️ Names: Mocha → LiveScript → JavaScript → ECMAScript
  • 🌐 Use Cases: Client-side, Backend (Node.js), Mobile apps, SPAs
  • ⚠️ Note: Java and JavaScript are completely different languages!

Why Learn JavaScript?

Advantages ✅Disadvantages ❌
  • Client-side execution (fast)
  • Browser validation
  • Easy to learn
  • No compiler needed
  • High speed
  • Versatile (frontend + backend)
  • Less secure (client-side code visible)
  • No direct hardware access
  • Browser compatibility issues

Prerequisites

Basic knowledge of HTML and CSS

🔧 Adding JavaScript to HTML

1. Inline JavaScript

<script> console.log("Hello, World!"); </script>

2. External JavaScript (Recommended)

<script src="script.js"></script>
💡 Best Practice: You can add multiple external JavaScript files. Place scripts at the end of the body for better performance.

Script Loading Strategies

MethodBehaviorUse When
Normal HTML parsing → Script download → Script execution → HTML parsing (blocking) Script depends on DOM being ready
async HTML parsing + Script download → Script execution → HTML parsing Independent scripts (analytics)
defer HTML parsing + Script download → HTML complete → Script execution Scripts that need full DOM (recommended)
<!-- Async --> <script src="script.js" async></script> <!-- Defer (Recommended) --> <script src="script.js" defer></script>

📤 JavaScript Output Methods

JavaScript can display data in different ways:

1. innerHTML - Modify HTML Element

document.getElementById("demo").innerHTML = "Hello World!";

2. document.write() - Write to HTML

document.write("Hello World!");
⚠️ Warning: Using document.write() after page load will delete all existing HTML!

3. window.alert() - Alert Box

window.alert("Hello World!"); // or simply alert("Hello World!");

4. console.log() - Browser Console (Most Common)

console.log("Hello World!"); console.log("Value:", 42); console.log({name: "John", age: 30});
💡 Best Practice: Use console.log() for debugging and development.

💬 Comments

Comments explain code and make it more readable. They are ignored by JavaScript.

Single-line Comments

// This is a single-line comment let x = 5; // This is also a comment

Multi-line Comments

/* This is a multi-line comment It can span multiple lines Very useful for documentation */ let y = 10;

📦 Variables

A variable is an identifier used to store and refer to a value.

var x = 5; var y = 6; var z = x + y; // z is 11

Variable Declaration Keywords

KeywordScopeReassignableHoistingUse When
var Function ✅ Yes ✅ Yes ❌ Avoid (legacy)
let Block ✅ Yes ❌ No ✅ Values that change
const Block ❌ No ❌ No ✅ Constants (recommended)
// var (old way - avoid) var name = "John"; // let (for values that change) let age = 30; age = 31; // OK // const (for constants - recommended) const PI = 3.14159; // PI = 3.14; // Error: Cannot reassign const
💡 Best Practice: Use const by default. Use let only when you need to reassign. Avoid var.

Variable Naming Rules

  • ✅ Must start with letter, $, or _
  • ✅ Can contain letters, numbers, $, _
  • ✅ Case-sensitive (myVar ≠ myvar)
  • ❌ Cannot use reserved keywords (let, class, return, etc.)
  • ✅ Use camelCase for readability (firstName, lastName)

🏷️ Data Types & Storage Architecture

Stack vs Heap Allocation

  • Primitives: Stored on the Stack. Fixed size, accessed by value, extremely fast.
  • Reference Types: Stored on the Heap. Dynamic size, accessed by reference (pointer on stack), subject to garbage collection.

Primitive Immortality

Primitives in JavaScript are Immutable. When you change a string, you are not modifying the old one; the engine creates a new string in memory and updates the variable's reference.

let str = "Hello"; str = str + " World"; // "Hello" is abandoned in memory; new string created.

⚙️ Operators

1. Arithmetic Operators

let a = 5; let b = 2; console.log(a + b); // 7 (Addition) console.log(a - b); // 3 (Subtraction) console.log(a * b); // 10 (Multiplication) console.log(a / b); // 2.5 (Division) console.log(a % b); // 1 (Modulus/Remainder) console.log(a ** 6); // 15625 (Exponentiation) a++; // Increment (a = 6) b--; // Decrement (b = 1)

2. Comparison Operators

let a = 5; let b = 2; let c = "5"; console.log(a > b); // true console.log(a < b); // false console.log(a >= b); // true console.log(a <= b); // false console.log(a == c); // true (loose equality) console.log(a === c); // false (strict equality) console.log(a != c); // false console.log(a !== c); // true

3. Logical Operators

let a = 5; let b = 2; console.log(a > b && b > a); // false (AND) console.log(a > b || b > a); // true (OR) console.log(!(a > b)); // false (NOT)

4. Assignment Operators

let x = 10; x += 5; // x = x + 5 → 15 x -= 3; // x = x - 3 → 12 x *= 2; // x = x * 2 → 24 x /= 4; // x = x / 4 → 6 x %= 4; // x = x % 4 → 2

⚖️ == vs === (Equality Operators)

OperatorNameComparesExample
== Abstract Equality Value only (type coercion) 5 == "5" → true
=== Strict Equality Value AND type 5 === "5" → false
// Abstract Equality (==) console.log(0 == false); // true console.log(1 == "1"); // true console.log(null == undefined); // true console.log('0' == false); // true // Strict Equality (===) - RECOMMENDED console.log(0 === false); // false console.log(1 === "1"); // false console.log(null === undefined); // false console.log('0' === false); // false // Objects and Arrays console.log([] == []); // false (different references) console.log([] === []); // false console.log({} == {}); // false console.log({} === {}); // false
💡 Best Practice: Always use === and !== to avoid unexpected type coercion bugs!

🔀 Conditional Statements

if Statement

let age = 18; if (age >= 18) { console.log("You are an adult"); }

if...else Statement

let age = 16; if (age >= 18) { console.log("You are an adult"); } else { console.log("You are a minor"); }

if...else if...else Statement

let score = 85; if (score >= 90) { console.log("Grade: A"); } else if (score >= 80) { console.log("Grade: B"); } else if (score >= 70) { console.log("Grade: C"); } else { console.log("Grade: F"); }

switch Statement

Alternative to multiple if...else statements

const day = "Tuesday"; switch(day) { case "Monday": console.log("Start of work week"); break; case "Tuesday": console.log("Second day of work"); break; case "Friday": console.log("Last work day!"); break; default: console.log("Regular day"); }
⚠️ Important: Don't forget break statements in switch cases, or execution will "fall through" to the next case!

🔄 Loops

for Loop

// Print numbers 1 to 5 for (let i = 1; i <= 5; i++) { console.log(i); } // Loop through array const fruits = ["Apple", "Banana", "Orange"]; for (let i = 0; i < fruits.length; i++) { console.log(fruits[i]); }

while Loop

let count = 1; while (count <= 5) { console.log(count); count++; }

do...while Loop

Executes at least once, then checks condition

let count = 1; do { console.log(count); count++; } while (count <= 5);

for...of Loop (ES6)

const fruits = ["Apple", "Banana", "Orange"]; for (let fruit of fruits) { console.log(fruit); }

⏸️ Break and Continue

break - Exit Loop

// Stop when i equals 5 for (let i = 1; i <= 10; i++) { if (i === 5) { break; // Exit loop } console.log(i); } // Output: 1, 2, 3, 4

continue - Skip Iteration

// Skip number 5 for (let i = 1; i <= 10; i++) { if (i === 5) { continue; // Skip this iteration } console.log(i); } // Output: 1, 2, 3, 4, 6, 7, 8, 9, 10
💡 Remember:
  • break - Exits the entire loop
  • continue - Skips current iteration and continues with next
