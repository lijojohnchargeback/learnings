⚡ JavaScript Functions

Complete Guide to Functions in JavaScript

📚 Introduction to Functions

In JavaScript, functions are First-Class Citizens. This means they are treated like any other variable: they can be passed as arguments, returned from other functions, and even have properties assigned to them like objects.

The "Function as Object" Reality

Technically, every function in JavaScript is a Function object. When you define a function, you are creating an instance of the Function class, which is why functions can have methods like .call() and .bind().

Architectural Benefits:
  • ✅ Abstraction: Hide complex implementation details behind a simple interface.
  • ✅ Avoidance of Side Effects: Using Pure Functions makes applications predictable and testable.
  • ✅ Memory Optimization: Shared logic reduces the footprint of the application.
// Basic function structure function greet(name) { return `Hello, ${name}!`; } console.log(greet("John")); // "Hello, John!"

📝 Function Declaration

A Function Declaration is a statement that defines a named function. Its primary characteristic is Hoisting.

The Mechanics of Hoisting

During the Creation Phase of the Execution Context, the JavaScript engine moves the entire function definition to the top of its scope. This is why you can invoke a declared function before its line of definition.

// Can be called before declaration due to Hoisting sayHi(); function sayHi() { console.log("Hi there!"); }

Parameters and Arguments

Parameters vs Arguments:

  • Parameters: Variables listed in function definition (firstName, lastName)
  • Arguments: Actual values passed when calling ("John", "Doe")
// Multiple parameters function calculateArea(width, height) { return width * height; } console.log(calculateArea(5, 10)); // 50 // No parameters function getCurrentTime() { return new Date().toLocaleTimeString(); } console.log(getCurrentTime()); // "4:30:15 PM"

Default Parameters (ES6)

// Default parameter values function greet(name = "Guest", greeting = "Hello") { return `${greeting}, ${name}!`; } console.log(greet()); // "Hello, Guest!" console.log(greet("John")); // "Hello, John!" console.log(greet("John", "Hi")); // "Hi, John!" // Real example: Create user profile function createUser(name, role = "user", isActive = true) { return { name: name, role: role, isActive: isActive, createdAt: new Date() }; } console.log(createUser("John")); // { name: "John", role: "user", isActive: true, createdAt: ... }

Rest Parameters (...)

// Rest parameters - collect remaining arguments into array function sum(...numbers) { return numbers.reduce((total, num) => total + num, 0); } console.log(sum(1, 2, 3)); // 6 console.log(sum(1, 2, 3, 4, 5)); // 15 // Combining regular and rest parameters function introduce(firstName, lastName, ...hobbies) { return `${firstName} ${lastName} likes: ${hobbies.join(", ")}`; } console.log(introduce("John", "Doe", "coding", "reading", "gaming")); // "John Doe likes: coding, reading, gaming"

Return Statement

// Function with return value function multiply(a, b) { return a * b; // Returns result } let result = multiply(5, 3); console.log(result); // 15 // Function without return (returns undefined) function logMessage(message) { console.log(message); // No return statement } let value = logMessage("Hello"); // Prints "Hello" console.log(value); // undefined // Early return function divide(a, b) { if (b === 0) { return "Cannot divide by zero"; } return a / b; } console.log(divide(10, 2)); // 5 console.log(divide(10, 0)); // "Cannot divide by zero"

Function Scope

// Variables declared inside function are local function testScope() { let localVar = "I'm local"; console.log(localVar); // Works } testScope(); // console.log(localVar); // Error: localVar is not defined // Global vs Local scope let globalVar = "I'm global"; function accessGlobal() { console.log(globalVar); // Can access global let localVar = "I'm local"; } accessGlobal(); // "I'm global"

✅ Key Characteristics:

  • Hoisted: Can be called before declaration in code
  • Named: Must have a function name
  • Function Scope: Creates its own scope for variables
  • this Binding: Has its own `this` context
  • arguments Object: Has access to `arguments` object

⚠️ Best Practices:

  • Use descriptive function names (verbs): calculateTotal, getUserData, validateEmail
  • Keep functions small and focused (single responsibility)
  • Avoid too many parameters (max 3-4 recommended)
  • Always return a value or undefined explicitly

💡 Function Expression

Assigning a function to a variable. This function can be named or anonymous, and it is not hoisted.

Temporal Dead Zone (TDZ):

Unlike declarations, expressions are treated like variables. If you use const or let, the function exists in a "dead zone" until the execution reaches the assignment line.

// Function Expression const getFullName = function(firstName, lastName) { return `${firstName} ${lastName}`; };

👤 Anonymous Functions

Use Case: Functions without names, typically used as callbacks.

// setTimeout with anonymous function setTimeout(function() { console.log("Executed after 3 seconds"); }, 3000); // Array method with anonymous function let numbers = [1, 2, 3, 4]; let doubled = numbers.map(function(num) { return num * 2; }); console.log(doubled); // [2, 4, 6, 8]

📌 Common Uses:

  • Callbacks (setTimeout, setInterval)
  • Array methods (map, filter, forEach)
  • Event handlers
  • One-time operations

➡️ Arrow Functions (ES6)

Arrow functions provide a concise syntax and lexical scoping for the this identifier.

The `this` Context Matrix

In regular functions, this is determined by how the function is called (Dynamic Scope). In arrow functions, this is determined by where the function is defined (Lexical Scope).

// Regular Function: 'this' depends on caller function User() { this.age = 0; setInterval(function() { this.age++; // Error: 'this' points to Global/Window }, 1000); } // Arrow Function: 'this' points to the User instance function UserFixed() { this.age = 0; setInterval(() => { this.age++; // Success: 'this' preserved lexically }, 1000); }

⚡ Closures & Data Privacy

A Closure is the combination of a function bundled together with references to its surrounding state (lexical environment).

The Persistent Scope

Even after a parent function has finished executing, a closure allows the child function to "remember" and access the variables of that parent. This is essential for State Management and Encapsulation.

// Closure Example function createCounter() { let count = 0; // Private state return function() { count++; return count; }; } const counter = createCounter(); console.log(counter()); // 1 console.log(counter()); // 2

🚀 Higher-Order Functions

Functions that accept or return other functions

// Higher-order function example function createMultiplier(multiplier) { return function(number) { return number * multiplier; }; } const double = createMultiplier(2); const triple = createMultiplier(3); console.log(double(5)); // 10 console.log(triple(5)); // 15 // Real example: Discount calculator function createDiscountCalculator(discountPercent) { return function(price) { return price * (1 - discountPercent / 100); }; } const apply20PercentOff = createDiscountCalculator(20); console.log(apply20PercentOff(100)); // 80

📚 Higher-Order Function Definition:

Functions that accept other functions as arguments OR return functions as values.

  • ✅ Accept functions as parameters
  • ✅ Return functions as results
  • ✅ Enable functional programming patterns

📞 Callback Functions

Functions passed as arguments to other functions

// Callback function example function processUserInput(callback) { let name = "John Doe"; callback(name); } processUserInput(function(name) { console.log(`Welcome, ${name}!`); }); // Real example: Array operations const numbers = [1, 2, 3, 4, 5]; numbers.forEach(function(num) { console.log(num * 2); });

🎯 Callback Function Uses:

  • Async Operations: Handle operations after completion
  • Event Handling: Respond to user interactions
  • Array Methods: map(), filter(), forEach()
  • Timer Functions: setTimeout(), setInterval()

🍛 Curry Functions

Transform function with multiple arguments into nested single-argument functions

// Normal function const add = (a, b, c) => a + b + c; console.log(add(2, 3, 5)); // 10 // Curried version const addCurry = (a) => (b) => (c) => a + b + c; console.log(addCurry(2)(3)(5)); // 10 // Real example: URL builder const buildURL = (protocol) => (domain) => (path) => `${protocol}://${domain}/${path}`; const https = buildURL("https"); const myWebsite = https("example.com"); console.log(myWebsite("about")); // "https://example.com/about"

💡 Currying Benefits:

  • Partial Application: Create specialized functions
  • Reusability: Build complex functions from simple ones
  • Functional Composition: Chain operations elegantly

✨ Pure Functions

Functions that don't modify external state (no side effects)

// Impure function (modifies external variable) let total = 0; function impureAdd(number) { total += number; return total; } // Pure function (no side effects) function pureAdd(a, b) { return a + b; } console.log(pureAdd(5, 3)); // 8 (always) // Real example: Calculate tax const calculateTax = (price, taxRate) => price * taxRate; console.log(calculateTax(100, 0.08)); // 8

✅ Pure Function Rules:

  • Same Input = Same Output: Predictable results
  • No Side Effects: Doesn't modify external state
  • No External Dependencies: Only uses parameters
  • Testable: Easy to test and debug

🔄 Generator Functions

Functions that can pause and resume, producing sequence of values

// Generator function function* numberGenerator() { yield 1; yield 2; yield 3; } const gen = numberGenerator(); console.log(gen.next().value); // 1 console.log(gen.next().value); // 2 console.log(gen.next().value); // 3 // Real example: ID generator function* idGenerator() { let id = 1; while (true) { yield id++; } } const ids = idGenerator(); console.log(ids.next().value); // 1 console.log(ids.next().value); // 2 console.log(ids.next().value); // 3

🔑 Generator Function Features:

  • Defined with `function*`: Asterisk notation
  • `yield` keyword: Pause and resume execution
  • Returns Iterator: Call `.next()` to get values
  • Lazy Evaluation: Generate values on demand

⏰ Timer Functions

setTimeout() - Execute Once After Delay

// Basic setTimeout setTimeout(() => { console.log("Executed after 2 seconds"); }, 2000); // Real example: Show notification function showNotification(message) { console.log(`Notification: ${message}`); // Auto-hide after 3 seconds setTimeout(() => { console.log("Notification hidden"); }, 3000); }

setInterval() - Execute Repeatedly

// Basic setInterval let counter = 0; const intervalId = setInterval(() => { counter++; console.log(`Counter: ${counter}`); if (counter >= 5) { clearInterval(intervalId); console.log("Stopped!"); } }, 1000); // Real example: Auto-save function startAutoSave() { return setInterval(() => { console.log("Auto-saving document..."); // saveDocument(); }, 30000); // Every 30 seconds }

clearTimeout() & clearInterval()

// Cancel setTimeout const timeoutId = setTimeout(() => { console.log("This won't run"); }, 5000); clearTimeout(timeoutId); // Cancelled! // Cancel setInterval const intervalId = setInterval(() => { console.log("Repeating..."); }, 1000); setTimeout(() => { clearInterval(intervalId); console.log("Stopped interval"); }, 5000);

⚡ Async Functions

Async functions make asynchronous code look synchronous, using Promises under the hood.

// Basic async function async function fetchData() { try { let response = await fetch("https://api.example.com/data"); let data = await response.json(); return data; } catch (error) { console.error("Error:", error); } } // Real example: Load user profile async function getUserProfile(userId) { try { const user = await fetch(`/api/users/${userId}`); const userData = await user.json(); const posts = await fetch(`/api/users/${userId}/posts`); const postsData = await posts.json(); return { user: userData, posts: postsData }; } catch (error) { console.error("Failed to load profile:", error); } } // Using the async function getUserProfile(123).then(profile => { console.log(profile); });
