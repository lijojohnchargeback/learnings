Complete Guide to String Manipulation

📚 Introduction to Strings

Strings are used for storing and manipulating text. A string can contain zero or more characters within quotes.

Real-World Examples

Strings are everywhere in programming:

  • 👤 User names: "John Doe"
  • 📧 Email addresses: "user@example.com"
  • 🏠 Addresses: "123 Main St, New York"
  • 📱 Phone numbers: "+1-555-123-4567"
  • 📝 Messages: "Welcome to our application!"

String Characteristics

  • ✅ Immutable: Cannot be changed once created
  • ✅ Primitive Type: But has methods via wrapper object
  • ✅ Unicode Support: Can contain any character
  • ✅ Zero-indexed: First character is at position 0

🔨 Creating Strings

Method 1: String Literals (Recommended)

// Single quotes let str1 = 'Hello World'; // Double quotes let str2 = "Hello World"; // Both are equivalent console.log(str1 === str2); // true // When to use which? let quote1 = "He said, 'Hello!'"; // Single quotes inside let quote2 = 'She said, "Hi!"'; // Double quotes inside

Method 2: String Constructor

// Using new String() (not recommended) const str1 = new String("Hello"); const str2 = "Hello"; console.log(typeof str1); // "object" console.log(typeof str2); // "string"
⚠️ Important: Always use string literals (quotes) instead of the String constructor. The constructor creates an object, not a primitive string.

💡 Negative indices (ES2022): [-5] [-4] [-3] [-2] [-1]

Use .at(-1) to access from the end!

let text = "I am good person"; // 1. Bracket notation (most common) console.log(text[0]); // "I" console.log(text[2]); // "a" // 2. charAt() method console.log(text.charAt(0)); // "I" console.log(text.charAt(2)); // "a" // 3. at() method (ES2022 - supports negative indices) console.log(text.at(0)); // "I" console.log(text.at(-1)); // "n" (last character) console.log(text.at(-2)); // "o" (second to last) // 4. charCodeAt() - Get UTF-16 code console.log(text.charCodeAt(0)); // 73 (UTF-16 code for "I") // Loop through string for (let i = 0; i < text.length; i++) { console.log(text[i]); } // Modern way with for...of for (let char of text) { console.log(char); }

String Length

let message = "Hello, World!"; console.log(message.length); // 13 // Real example: Validate password length function isValidPassword(password) { return password.length >= 8; } console.log(isValidPassword("abc123")); // false console.log(isValidPassword("abc12345")); // true

🔒 String Immutability

Strings are immutable - once created, they cannot be changed. All string methods return NEW strings.

🔒 Immutability Demonstration

Original String

"Hello"

Stored in memory

→

.toUpperCase()

"HELLO"

New string created

⚠️ Key Point: Original string "Hello" remains unchanged in memory!

Why Immutability Matters

  • ✅ Predictability: Original values never change
  • ✅ Thread-safe: Safe for concurrent operations
  • ✅ Caching: Same strings can be reused
  • ✅ Security: Cannot be modified after creation
// Strings are immutable let original = "Hello"; let upper = original.toUpperCase(); console.log(original); // "Hello" (unchanged) console.log(upper); // "HELLO" (new string) // You CANNOT modify individual characters let word = "Hello"; word[0] = "J"; // This doesn't work! console.log(word); // Still "Hello" // Instead, create a new string word = "J" + word.slice(1); console.log(word); // "Jello"

🔤 Case Conversion

let text = "Hello World"; console.log(text.toUpperCase()); // "HELLO WORLD" console.log(text.toLowerCase()); // "hello world" // Real example: Case-insensitive comparison function compareEmails(email1, email2) { return email1.toLowerCase() === email2.toLowerCase(); } console.log(compareEmails("User@Example.com", "user@example.com")); // true

✂️ Trimming Whitespace

trim(), trimStart(), trimEnd()

let text = " Hello World "; console.log(text.trim()); // "Hello World" console.log(text.trimStart()); // "Hello World " console.log(text.trimEnd()); // " Hello World" // Real example: Validate input function validateUsername(username) { const cleaned = username.trim(); return cleaned.length >= 3; } console.log(validateUsername(" john ")); // true

🔄 Replacing Text

replace() & replaceAll()

let text = "Please visit Microsoft and Microsoft!"; // Replace first occurrence let newText = text.replace("Microsoft", "Google"); console.log(newText); // "Please visit Google and Microsoft!" // Replace all occurrences with regex /g flag let allReplaced = text.replace(/Microsoft/g, "Google"); console.log(allReplaced); // "Please visit Google and Google!" // replaceAll() - ES2021 (cleaner than regex) let all = text.replaceAll("Microsoft", "Google"); console.log(all); // "Please visit Google and Google!" // Case-insensitive replace with /i flag let text2 = "Please visit MICROSOFT!"; let replaced = text2.replace(/microsoft/i, "Google"); console.log(replaced); // "Please visit Google!" // Real example: Censor bad words function censorText(text) { return text .replace(/badword1/gi, "***") .replace(/badword2/gi, "***"); }

📏 Slicing & Extraction

slice(), substring(), substr()

let text = "Hello World"; // slice(start, end) - extracts a portion console.log(text.slice(0, 5)); // "Hello" console.log(text.slice(6)); // "World" console.log(text.slice(-5)); // "World" (negative = from end) // substring(start, end) - similar to slice console.log(text.substring(0, 5)); // "Hello" // Real example: Get file extension function getFileExtension(filename) { const lastDot = filename.lastIndexOf("."); return filename.slice(lastDot + 1); } console.log(getFileExtension("document.pdf")); // "pdf"

🔀 Splitting Strings

split() - String to Array

let text = "apple,banana,orange"; let fruits = text.split(","); console.log(fruits); // ["apple", "banana", "orange"] // Split by space let sentence = "Hello World from JavaScript"; let words = sentence.split(" "); console.log(words); // ["Hello", "World", "from", "JavaScript"] // Split into characters let name = "John"; let letters = name.split(""); console.log(letters); // ["J", "o", "h", "n"] // Real example: Parse CSV data function parseCSV(csvLine) { return csvLine.split(",").map(item => item.trim()); } let data = parseCSV("John, 30, Developer"); console.log(data); // ["John", "30", "Developer"]

🔎 Searching in Strings

let text = "Hello World, Hello JavaScript"; // indexOf() - Find first occurrence console.log(text.indexOf("Hello")); // 0 console.log(text.indexOf("World")); // 6 console.log(text.indexOf("Python")); // -1 (not found) // lastIndexOf() - Find last occurrence console.log(text.lastIndexOf("Hello")); // 13 // search() - Search with regex console.log(text.search(/world/i)); // 6 (case-insensitive)

✅ Checking Strings

includes(), startsWith(), endsWith()

let text = "Hello World from JavaScript"; // Check if string contains console.log(text.includes("World")); // true console.log(text.includes("Python")); // false // Check if starts with console.log(text.startsWith("Hello")); // true console.log(text.startsWith("World")); // false // Check if ends with console.log(text.endsWith("JavaScript")); // true console.log(text.endsWith("World")); // false // Real example: Check email domain function isGmailAddress(email) { return email.toLowerCase().endsWith("@gmail.com"); } console.log(isGmailAddress("user@gmail.com")); // true console.log(isGmailAddress("user@yahoo.com")); // false

📐 Padding & Repeating

repeat(), padStart(), padEnd()

// repeat() - Repeat string console.log("Ha".repeat(3)); // "HaHaHa" console.log("*".repeat(10)); // "**********" // padStart() - Pad from start console.log("5".padStart(3, "0")); // "005" // padEnd() - Pad from end console.log("5".padEnd(3, "0")); // "500" // Real example: Format credit card function formatCardNumber(last4) { return "**** **** **** " + last4.padStart(4, "0"); } console.log(formatCardNumber("1234")); // "**** **** **** 1234"

✨ Template Literals (ES6)

Template literals provide an elegant way to work with strings, supporting multi-line strings and embedded expressions.

Basic Syntax

// Old way (concatenation) let name = "John"; let age = 30; let message = "Hello, my name is " + name + " and I am " + age + " years old."; // New way (template literals) let message2 = `Hello, my name is ${name} and I am ${age} years old.`; console.log(message2);

Multi-line Strings

// Old way (with \n) let text1 = "Line 1\nLine 2\nLine 3"; // New way (template literals) let text2 = `Line 1 Line 2 Line 3`; console.log(text2);

Expression Evaluation

let price = 100; let tax = 0.08; let message = `Total: $${(price * (1 + tax)).toFixed(2)}`; console.log(message); // "Total: $108.00" // Real example: Generate HTML function createUserCard(user) { return ` <div class="user-card"> <h2>${user.name}</h2> <p>Email: ${user.email}</p> <p>Age: ${user.age}</p> </div> `; } let user = { name: "John", email: "john@example.com", age: 30 }; console.log(createUserCard(user));
