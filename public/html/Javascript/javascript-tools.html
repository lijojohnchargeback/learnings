🛠️ JavaScript Development Tools

Essential Tools for Modern JavaScript Development

🧹 Code Quality & Linting

1. ESLint

Purpose: Finds and fixes problems in JavaScript code

Why Use:

  • ✅ Catch bugs before runtime
  • ✅ Enforce coding standards
  • ✅ Integrates with editors
# Install npm install -g eslint # Initialize eslint --init # Run linting npm run lint # Auto-fix issues npm run lint:fix

2. Prettier

Purpose: Opinionated code formatter

Why Use:

  • ✅ Consistent code style
  • ✅ No style debates in team
  • ✅ Works with ESLint
# Install npm install --save-dev prettier # Format all files npx prettier --write .

3. Stylelint

Purpose: Linter for CSS/SCSS

When to Use: Projects with custom styles

Real-World Setup

Typical Project Setup:

  1. ESLint for JavaScript linting
  2. Prettier for code formatting
  3. Configure editor (VS Code) to auto-format on save
  4. Add pre-commit hooks to enforce standards

🏗️ Build Tools & Bundlers

4. Webpack

Purpose: Module bundler for JavaScript applications

Features:

  • 📦 Bundles JS, CSS, images
  • 🔄 Code splitting
  • ⚡ Hot Module Replacement (HMR)
  • 🔌 Extensive plugin ecosystem

When to Use: Complex applications, legacy projects

5. Vite

Purpose: Next-generation frontend tooling

Features:

  • ⚡ Lightning-fast dev server
  • 🚀 Instant server start
  • 🔥 Hot Module Replacement
  • 📦 Optimized builds

When to Use: Modern React/Vue/Svelte projects

# Create new project npm create vite@latest my-app # Start dev server npm run dev

6. Parcel

Purpose: Zero-config bundler

When to Use: Quick prototypes, simple projects

7. Rollup

Purpose: Module bundler for libraries

When to Use: Building JavaScript libraries

Choosing a Build Tool

  • 🚀 New projects: Use Vite (fastest, modern)
  • ⚛️ React apps: Create React App or Vite
  • 📚 Libraries: Rollup
  • 🏢 Enterprise apps: Webpack (most configurable)

🔬 Testing Frameworks

Best For: Unit testing, React applications

Features:

  • Zero config
  • Snapshot testing
  • Built-in code coverage
  • Mocking support
// Example test test('adds 1 + 2 to equal 3', () => { expect(1 + 2).toBe(3); }); test('array contains item', () => { const arr = ['apple', 'banana']; expect(arr).toContain('apple'); });

12. Mocha + Chai

Purpose: Test runner + assertion library

Best For: Node.js applications

13. Vitest

Purpose: Vite-native testing framework

Best For: Projects using Vite

14. Cypress

Purpose: End-to-end testing

Best For: Testing entire user flows

Testing Strategy

Recommended Approach:

🧪 Code Coverage Tools

Code coverage measures how much of your code is executed during testing.

Istanbul / nyc

Purpose: JavaScript code coverage tool

Works with: Jest, Mocha, Jasmine

# Install npm install --save-dev nyc # Run tests with coverage nyc npm test # Generate HTML report nyc --reporter=html npm test

Jest Coverage

Purpose: Built-in coverage in Jest

# Run with coverage npm test -- --coverage # package.json { "scripts": { "test": "jest", "test:coverage": "jest --coverage" } }

Codecov

Purpose: Hosted coverage reports

Features:

  • Visual coverage reports
  • GitHub integration
  • Pull request comments
  • Coverage badges

Coveralls

Purpose: Coverage tracking service

Similar to: Codecov

Understanding Coverage Metrics

Metric Description Goal
Statement Coverage % of statements executed 80-90%
Branch Coverage % of branches (if/else) executed 75-85%
Function Coverage % of functions called 80-90%
Line Coverage % of lines executed 80-90%

💡 Coverage Tips:

  • ✅ Aim for 80% coverage as a baseline
  • ✅ 100% coverage doesn't guarantee bug-free code
  • ✅ Focus on testing critical paths
  • ✅ Use coverage to find untested code
  • ⚠️ Don't sacrifice test quality for coverage numbers

⚙️ Task Runners

Task runners automate repetitive development tasks.

npm scripts

Purpose: Built-in task runner in package.json

Advantages:

  • No additional tool needed
  • Simple and straightforward
  • Most common approach
// package.json { "scripts": { "start": "node server.js", "dev": "nodemon server.js", "build": "webpack --mode production", "test": "jest", "test:watch": "jest --watch", "lint": "eslint .", "lint:fix": "eslint . --fix", "format": "prettier --write .", "clean": "rm -rf dist", "prebuild": "npm run clean" } } # Run scripts npm run dev npm run build npm test

Gulp

Purpose: Streaming task runner

When to Use: Complex build pipelines

// gulpfile.js const gulp = require('gulp'); const sass = require('gulp-sass'); const concat = require('gulp-concat'); gulp.task('styles', () => { return gulp.src('src/*.scss') .pipe(sass()) .pipe(gulp.dest('dist/css')); }); gulp.task('watch', () => { gulp.watch('src/*.scss', gulp.series('styles')); });

Grunt

Purpose: Task runner (older than Gulp)

Status: Less popular now, mostly legacy

Make (Makefile)

Purpose: Cross-language build tool

When to Use: Multi-language projects

# Makefile .PHONY: install build test install: npm install build: npm run build test: npm test clean: rm -rf dist node_modules

Choosing a Task Runner

  • 🥇 First choice: npm scripts (simplest)
  • 🏗️ Complex tasks: Gulp (streaming)
  • 🔧 Multi-language: Make or Invoke
  • 🚫 Avoid: Grunt (outdated)

📐 JavaScript Math Methods

The Math object provides mathematical constants and functions. All properties and methods of Math are static.

Common Math Methods

Math.abs(x)

Purpose: Returns the absolute value of x (never negative)

Math.abs(7.25); // 7.25 Math.abs(-7.25); // 7.25 Math.abs(null); // 0 Math.abs("Hello"); // NaN Math.abs(2-3); // 1

Math.ceil(x)

Purpose: Rounds x upwards to nearest integer

Math.ceil(0.60); // 1 Math.ceil(0.40); // 1 Math.ceil(5); // 5 Math.ceil(5.1); // 6 Math.ceil(-5.1); // -5 Math.ceil(-5.9); // -5

Math.floor(x)

Purpose: Rounds x downwards to nearest integer

Math.floor(0.60); // 0 Math.floor(0.40); // 0 Math.floor(5); // 5 Math.floor(5.9); // 5 Math.floor(-5.1); // -6 Math.floor(-5.9); // -6

Math.round(x)

Purpose: Rounds x to nearest integer

Math.round(2.60); // 3 Math.round(2.50); // 3 Math.round(2.49); // 2 Math.round(-2.60); // -3 Math.round(-2.50); // -2

Math.max()

Purpose: Returns the highest value

Math.max(5, 10); // 10 Math.max(0, 150, 30, 20); // 150 Math.max(-5, 10); // 10 Math.max(-5, -10); // -5 Math.max(1.5, 2.5); // 2.5

Math.min()

Purpose: Returns the lowest value

Math.min(5, 10); // 5 Math.min(0, 150, 30, 20); // 0 Math.min(-5, 10); // -5 Math.min(-5, -10); // -10 Math.min(1.5, 2.5); // 1.5

Math.pow(x, y)

Purpose: Returns x to the power of y

Math.pow(0, 1); // 0 Math.pow(1, 1); // 1 Math.pow(1, 10); // 1 Math.pow(3, 3); // 27 Math.pow(-3, 3); // -27 Math.pow(2, 4); // 16 (2² = 4)

Math.sqrt(x)

Purpose: Returns the square root of x

Math.sqrt(0); // 0 Math.sqrt(1); // 1 Math.sqrt(9); // 3 Math.sqrt(64); // 8 Math.sqrt(-9); // NaN

Math.random()

Purpose: Returns random number between 0 and 1

// Random number 0-10 let x = Math.random() * 10; // Random whole number 1-10 let y = Math.floor(Math.random() * 10) + 1; // Random number in range function randomRange(min, max) { return Math.floor(Math.random() * (max - min + 1)) + min; }

Math.trunc(x)

Purpose: Returns integer part (removes decimal)

Math.trunc(4.9); // 4 Math.trunc(4.1); // 4 Math.trunc(-4.9); // -4 Math.trunc(-4.1); // -4

Math.sign(x)

Purpose: Returns sign of a number

Math.sign(5); // 1 (positive) Math.sign(-5); // -1 (negative) Math.sign(0); // 0 (zero) Math.sign(-0); // -0

Math Constants

Constant Description Value
Math.PI Pi (π) 3.14159...
Math.E Euler's number 2.718...
Math.LN2 Natural log of 2 0.693...
Math.SQRT2 Square root of 2 1.414...

💡 Quick Reference:

  • Rounding: Use Math.round(), Math.ceil(), or Math.floor()
  • Random numbers: Math.random() combined with Math.floor()
  • Min/Max: Find smallest/largest with Math.min() and Math.max()
  • Power/Root: Math.pow(x, y) or x ** y for power, Math.sqrt() for square root

🔢 JavaScript Number Methods

The Number object wraps primitive number values and provides useful methods and properties.

Number Validation Methods

Number.isFinite()

Purpose: Checks if value is a finite number

Number.isFinite(123); // true Number.isFinite("123"); // false (string) Number.isFinite(Infinity); // false Number.isFinite(1.2); // true Number.isFinite(NaN); // false

Number.isInteger()

Purpose: Checks if value is an integer

Number.isInteger(123); // true Number.isInteger(-123); // true Number.isInteger('123'); // false Number.isInteger(4-2); // true (= 2) Number.isInteger(4/2); // true (= 2) Number.isInteger(5/2); // false (= 2.5)

Number.isNaN()

Purpose: Checks if value is NaN

Number.isNaN(NaN); // true Number.isNaN("Hello"); // false Number.isNaN(undefined); // false Number.isNaN(123); // false

Number.isSafeInteger()

Purpose: Checks if value is safe integer

Number.isSafeInteger(123); // true Number.isSafeInteger(1.5); // false Number.isSafeInteger(9007199254740992); // false

Number Conversion Methods

parseInt()

Purpose: Parses string and returns whole number

parseInt("10"); // 10 parseInt("10.5"); // 10 parseInt("10 years"); // 10 parseInt("years 10"); // NaN parseInt("10", 2); // 2 (binary) parseInt("10", 16); // 16 (hex)

parseFloat()

Purpose: Parses string and returns decimal number

parseFloat("10"); // 10 parseFloat("10.5"); // 10.5 parseFloat("10.5.2"); // 10.5 parseFloat("10 20"); // 10

toString()

Purpose: Converts number to string

let num = 123; num.toString(); // "123" num.toString(2); // "1111011" (binary) num.toString(16); // "7b" (hex)

toFixed(x)

Purpose: Formats number with x decimal places

let num = 5.56789; num.toFixed(0); // "6" num.toFixed(2); // "5.57" num.toFixed(4); // "5.5679"

toPrecision(x)

Purpose: Formats number to x total digits

let num = 5.56789; num.toPrecision(2); // "5.6" num.toPrecision(4); // "5.568" num.toPrecision(6); // "5.56789"

toExponential(x)

Purpose: Converts to exponential notation

let num = 123456; num.toExponential(2); // "1.23e+5" num.toExponential(4); // "1.2346e+5"

Number Properties

Property Description Value
Number.MAX_VALUE Largest possible number 1.7976931348623157e+308
Number.MIN_VALUE Smallest possible positive number 5e-324
Number.MAX_SAFE_INTEGER Largest safe integer 9007199254740991
Number.MIN_SAFE_INTEGER Smallest safe integer -9007199254740991
Number.POSITIVE_INFINITY Represents positive infinity Infinity
Number.NEGATIVE_INFINITY Represents negative infinity -Infinity
Number.NaN Represents "Not-a-Number" NaN
Number.EPSILON Smallest interval between numbers 2.220446049250313e-16

💡 Best Practices:

  • Use Number.isNaN() instead of isNaN() for accurate NaN checks
  • Use toFixed() for displaying prices and currency
  • Always specify radix parameter in parseInt() to avoid unexpected results
  • Check Number.isSafeInteger() when working with large integers

📅 JavaScript Date Methods

The Date object is used to work with dates and times in JavaScript.

Creating Dates

// Current date and time let now = new Date(); // Specific date (year, month, day, hours, minutes, seconds) let date1 = new Date(2024, 0, 15); // Month is 0-indexed (0 = Jan) let date2 = new Date(2024, 0, 15, 10, 30, 0); // From string let date3 = new Date("2024-01-15"); let date4 = new Date("January 15, 2024"); // From milliseconds (since Jan 1, 1970) let date5 = new Date(1705276800000);

Get Date Methods

Basic Get Methods

let date = new Date(); date.getFullYear(); // 2024 date.getMonth(); // 0-11 (0 = Jan) date.getDate(); // 1-31 (day of month) date.getDay(); // 0-6 (0 = Sunday) date.getHours(); // 0-23 date.getMinutes(); // 0-59 date.getSeconds(); // 0-59 date.getMilliseconds(); // 0-999

UTC Get Methods

let date = new Date(); date.getUTCFullYear(); date.getUTCMonth(); date.getUTCDate(); date.getUTCDay(); date.getUTCHours(); date.getUTCMinutes(); date.getUTCSeconds();

getTime()

Purpose: Returns milliseconds since Jan 1, 1970

let date = new Date(); date.getTime(); // 1705276800000 // Same as: Date.now(); // Current timestamp

getTimezoneOffset()

Purpose: Returns time difference from UTC (in minutes)

let date = new Date(); date.getTimezoneOffset(); // -300 (5 hours)

Set Date Methods

Basic Set Methods

let date = new Date(); date.setFullYear(2025); date.setMonth(11); // December date.setDate(25); // 25th day date.setHours(10); date.setMinutes(30); date.setSeconds(0); date.setMilliseconds(0);

UTC Set Methods

let date = new Date(); date.setUTCFullYear(2025); date.setUTCMonth(0); date.setUTCDate(1); date.setUTCHours(0); date.setUTCMinutes(0); date.setUTCSeconds(0);

setTime()

Purpose: Sets date from milliseconds

let date = new Date(); date.setTime(1705276800000); // Add 1 day (86400000 ms) date.setTime(date.getTime() + 86400000);

Date Formatting Methods

toString Methods

let date = new Date(); date.toString(); // "Sun Dec 31 2025 10:30:00 GMT+0000" date.toDateString(); // "Sun Dec 31 2025" date.toTimeString(); // "10:30:00 GMT+0000"

Locale Methods

let date = new Date(); date.toLocaleDateString(); // "12/31/2025" (US) date.toLocaleTimeString(); // "10:30:00 AM" date.toLocaleString(); // "12/31/2025, 10:30:00 AM"

ISO & UTC Methods

let date = new Date(); date.toISOString(); // "2025-12-31T10:30:00.000Z" date.toUTCString(); // "Sun, 31 Dec 2025 10:30:00 GMT" date.toJSON(); // "2025-12-31T10:30:00.000Z"

Date Calculations

// Get current timestamp let now = Date.now(); // Static method // Calculate difference between dates let date1 = new Date("2024-01-01"); let date2 = new Date("2024-12-31"); let diff = date2 - date1; // Milliseconds let days = diff / (1000 * 60 * 60 * 24); // Convert to days // Add days to a date let today = new Date(); let tomorrow = new Date(today); tomorrow.setDate(tomorrow.getDate() + 1); // Add months let nextMonth = new Date(today); nextMonth.setMonth(nextMonth.getMonth() + 1); // Compare dates if (date1 > date2) { console.log("date1 is later"); } // Parse date string let ms = Date.parse("2024-01-15"); // Returns milliseconds

Common Date Patterns

Task Method Example
Get current date new Date() let now = new Date();
Get timestamp Date.now() let ts = Date.now();
Format date toLocaleDateString() date.toLocaleDateString()
Get year getFullYear() date.getFullYear()
Get month name toLocaleString() date.toLocaleString('en', {month: 'long'})
Check if valid date isNaN() !isNaN(date.getTime())

⚠️ Common Date Pitfalls:

  • Months are 0-indexed: January = 0, December = 11
  • Days are 1-indexed: 1st = 1, 31st = 31
  • Week days are 0-indexed: Sunday = 0, Saturday = 6
  • Date constructor: new Date(2024, 0) creates Jan 1, not Feb 1
  • Timezone issues: Be aware of local vs UTC methods

💡 Pro Tips:

  • Use Date.now() instead of new Date().getTime() for timestamps
  • For complex date manipulation, consider libraries like date-fns or Day.js
  • Always validate date inputs from users
  • Use ISO format (YYYY-MM-DD) for consistent date strings
  • Store dates in UTC, display in local timezone
