1. FizzBuzz

Problem: Print 1..n; multiples of 3→Fizz, 5→Buzz, both→FizzBuzz.

Example: n=5 → ["1","2","Fizz","4","Buzz"]

Approach: Loop; check %15 before %3/%5.

🐍 Python

def fizzbuzz(n): out=[] for i in range(1,n+1): if i%15==0: out.append("FizzBuzz") elif i%3==0: out.append("Fizz") elif i%5==0: out.append("Buzz") else: out.append(str(i)) return out

⚡ JavaScript

function fizzbuzz(n){ const out=[]; for(let i=1;i<=n;i++){ if(i%15===0) out.push("FizzBuzz"); else if(i%3===0) out.push("Fizz"); else if(i%5===0) out.push("Buzz"); else out.push(String(i)); } return out; }
TimeSpacePattern
O(n)O(n)Conditionals

Approach: Slice or two pointers on a char array.

def reverse_string(s): return s[::-1]

⚡ JavaScript

function reverseString(s){ return s.split("").reverse().join(""); }
TimeSpacePattern
O(n)O(n)Two pointers / built-in

def is_palindrome(x): if x<0: return False s=str(x) return s==s[::-1]

⚡ JavaScript

function isPalindrome(x){ if(x<0) return false; const s=String(x); return s===s.split("").reverse().join(""); }

O(d)O(d)Two pointers

4. Two Sum

Problem: Return indices of two numbers that add to target.

Example: [2,7,11,15], 9 → [0,1]

Approach: One-pass hash map of value→index.

🐍 Python

def two_sum(nums,target): seen={} for i,n in enumerate(nums): if target-n in seen: return [seen[target-n],i] seen[n]=i return []

⚡ JavaScript

function twoSum(nums,target){ const seen=new Map(); for(let i=0;i<nums.length;i++){ const need=target-nums[i]; if(seen.has(need)) return [seen.get(need),i]; seen.set(nums[i],i); } return []; }
TimeSpacePattern
O(n)O(n)Hash map

5. Max and Min

Problem: Return max and min in an array.

Example: [3,1,9,2] → {max:9,min:1}

Approach: Single pass track running max/min.

🐍 Python

def max_min(nums): mx=mn=nums[0] for n in nums[1:]: mx=max(mx,n); mn=min(mn,n) return {"max":mx,"min":mn}

⚡ JavaScript

function maxMin(nums){ let mx=mn=nums[0]; for(let i=1;i<nums.length;i++){ mx=Math.max(mx,nums[i]); mn=Math.min(mn,nums[i]); } return {max:mx,min:mn}; }
TimeSpacePattern
O(n)O(1)Single pass

6. Count Vowels

Problem: Count aeiou (case-insensitive) in a string.

Example: "Hello" → 2

Approach: Set of vowels; count membership.

🐍 Python

def count_vowels(s): v=set("aeiouAEIOU") return sum(1 for c in s if c in v)

⚡ JavaScript

function countVowels(s){ const v=new Set("aeiouAEIOU"); let c=0; for(const ch of s) if(v.has(ch)) c++; return c; }
TimeSpacePattern
O(n)O(1)Set

7. Remove Duplicates (Sorted)

Problem: In-place unique prefix on sorted array; return new length.

Example: [1,1,2] → 2, [1,2,_]

Approach: Slow/fast two pointers.

🐍 Python

def remove_duplicates(nums): if not nums: return 0 s=0 for f in range(1,len(nums)): if nums[f]!=nums[s]: s+=1; nums[s]=nums[f] return s+1

⚡ JavaScript

function removeDuplicates(nums){ if(!nums.length) return 0; let s=0; for(let f=1;f<nums.length;f++){ if(nums[f]!==nums[s]){ s++; nums[s]=nums[f]; } } return s+1; }
TimeSpacePattern
O(n)O(1)Two pointers

13. Check Prime

Problem: True if n is prime (n>1).

Example: 7 → true; 9 → false

Approach: Trial divide up to sqrt(n).

🐍 Python

import math def is_prime(n): if n<=1: return False for i in range(2,int(math.sqrt(n))+1): if n%i==0: return False return True

⚡ JavaScript

function isPrime(n){ if(n<=1) return false; for(let i=2;i*i<=n;i++) if(n%i===0) return false; return true; }
TimeSpacePattern
O(√n)O(1)Math

16. Missing Number

Problem: Array of n distinct in 0..n; find the missing one.

Example: [3,0,1] → 2

Approach: XOR all indices and values, or Gauss sum.

🐍 Python

def missing_number(nums): n=len(nums) return n*(n+1)//2 - sum(nums)

⚡ JavaScript

function missingNumber(nums){ const n=nums.length; return n*(n+1)/2 - nums.reduce((a,b)=>a+b,0); }
TimeSpacePattern
O(n)O(1)Math / XOR

17. Move Zeroes

Problem: Move all 0s to end, keep relative order of others.

Example: [0,1,0,3,12] → [1,3,12,0,0]

Approach: Slow pointer for next non-zero write.

🐍 Python

def move_zeroes(nums): s=0 for f in range(len(nums)): if nums[f]!=0: nums[s],nums[f]=nums[f],nums[s] s+=1 return nums

⚡ JavaScript

function moveZeroes(nums){ let s=0; for(let f=0;f<nums.length;f++){ if(nums[f]!==0){ [nums[s],nums[f]]=[nums[f],nums[s]]; s++; } } return nums; }
TimeSpacePattern
O(n)O(1)Two pointers

18. Plus One

Problem: Digits of a large integer as array; add one.

Example: [1,2,9] → [1,3,0]

Approach: Carry from the end; prepend 1 if needed.

🐍 Python

def plus_one(digits): for i in range(len(digits)-1,-1,-1): if digits[i]<9: digits[i]+=1; return digits digits[i]=0 return [1]+digits

⚡ JavaScript

function plusOne(digits){ for(let i=digits.length-1;i>=0;i--){ if(digits[i]<9){ digits[i]++; return digits; } digits[i]=0; } return [1,...digits]; }
TimeSpacePattern
O(n)O(1)Carry

function intersection(a,b){ const sb=new Set(b); return [...new Set(a.filter(x=>sb.has(x)))]; }

20. Majority Element

Problem: Element appearing more than n/2 times (guaranteed).

Example: [2,2,1,1,1,2,2] → 2

Approach: Boyer-Moore voting or hash count.

🐍 Python

def majority_element(nums): cand=None; count=0 for n in nums: if count==0: cand=n count+=1 if n==cand else -1 return cand

⚡ JavaScript

function majorityElement(nums){ let cand=null,count=0; for(const n of nums){ if(count===0) cand=n; count+= n===cand?1:-1; } return cand; }
TimeSpacePattern
O(n)O(1)Boyer-Moore

23. Best Time to Buy/Sell Stock I

🐍 Python

def max_profit(prices): mn=float("inf"); best=0 for p in prices: mn=min(mn,p); best=max(best,p-mn) return best

function maxProfit(prices){ let mn=Infinity,best=0; for(const p of prices){ mn=Math.min(mn,p); best=Math.max(best,p-mn); } return best; }

O(n)O(1)Running min

24. Valid Parentheses

Problem: True if brackets (),{},[] are correctly matched.

Example: "()[]{}" → true

Approach: Stack of opening brackets.

🐍 Python

def is_valid(s): pair={")":"(","]":"[","}":"{"}; st=[] for c in s: if c in pair: if not st or st.pop()!=pair[c]: return False else: st.append(c) return not st

⚡ JavaScript

function isValid(s){ const pair={")":"(","]":"[","}":"{"}, st=[]; for(const c of s){ if(c in pair){ if(st.pop()!==pair[c]) return false; } else st.push(c); } return st.length===0; }

O(n)O(n)Stack

25. Merge Two Sorted Arrays

Problem: Merge two sorted arrays into one sorted array.

Example: [1,3],[2,4] → [1,2,3,4]

Approach: Two pointers from starts.

🐍 Python

def merge(a,b): i=j=0; out=[] while i<len(a) and j<len(b): if a[i]<=b[j]: out.append(a[i]); i+=1 else: out.append(b[j]); j+=1 return out+a[i:]+b[j:]

⚡ JavaScript

function merge(a,b){ let i=0,j=0; const out=[]; while(i<a.length&&j<b.length){ if(a[i]<=b[j]) out.push(a[i++]); else out.push(b[j++]); } return out.concat(a.slice(i),b.slice(j)); }
TimeSpacePattern
O(n+m)O(n+m)Two pointers

26. Reverse Linked List

Problem: Reverse a singly linked list; return new head.

Example: 1→2→3 → 3→2→1

Approach: Iterative prev/curr/next pointers.

🐍 Python

def reverse_list(head): prev=None while head: nxt=head.next head.next=prev prev=head head=nxt return prev

⚡ JavaScript

function reverseList(head){ let prev=null; while(head){ const nxt=head.next; head.next=prev; prev=head; head=nxt; } return prev; }

O(n)O(1)Linked list

27. Middle of Linked List

Problem: Return the middle node (second middle if even).

Example: 1→2→3→4→5 → 3

Approach: Slow/fast: fast moves 2, slow 1.

🐍 Python

def middle_node(head): slow=fast=head while fast and fast.next: slow=slow.next; fast=fast.next.next return slow

⚡ JavaScript

function middleNode(head){ let slow=head,fast=head; while(fast&&fast.next){ slow=slow.next; fast=fast.next.next; } return slow; }
TimeSpacePattern
O(n)O(1)Two pointers

28. Happy Number

Problem: Replace n by sum of squares of digits; true if reaches 1.

Example: 19 → true

Approach: Floyd cycle or set of seen values.

🐍 Python

def is_happy(n): def nxt(x): return sum(int(d)**2 for d in str(x)) seen=set() while n!=1 and n not in seen: seen.add(n); n=nxt(n) return n==1

⚡ JavaScript

function isHappy(n){ const nxt=x=>String(x).split("").reduce((a,d)=>a+(+d)**2,0); const seen=new Set(); while(n!==1&&!seen.has(n)){ seen.add(n); n=nxt(n); } return n===1; }
TimeSpacePattern
O(log n)O(log n)Cycle detection

29. Roman to Integer

Problem: Convert Roman numeral string to integer.

Example: "MCMXCIV" → 1994

Approach: Scan; if next > current, subtract.

🐍 Python

def roman_to_int(s): val={"I":1,"V":5,"X":10,"L":50,"C":100,"D":500,"M":1000} total=0 for i,c in enumerate(s): if i+1<len(s) and val[c]<val[s[i+1]]: total-=val[c] else: total+=val[c] return total

⚡ JavaScript

function romanToInt(s){ const val={I:1,V:5,X:10,L:50,C:100,D:500,M:1000}; let total=0; for(let i=0;i<s.length;i++){ if(i+1<s.length&&val[s[i]]<val[s[i+1]]) total-=val[s[i]]; else total+=val[s[i]]; } return total; }
TimeSpacePattern
O(n)O(1)Map lookup

30. Longest Common Prefix

Problem: Longest shared prefix among string array.

Example: ["flower","flow","flight"] → "fl"

Approach: Vertical scan char by char.

🐍 Python

def longest_common_prefix(strs): if not strs: return "" for i,ch in enumerate(strs[0]): for s in strs[1:]: if i>=len(s) or s[i]!=ch: return strs[0][:i] return strs[0]

⚡ JavaScript

function longestCommonPrefix(strs){ if(!strs.length) return ""; for(let i=0;i<strs[0].length;i++){ const ch=strs[0][i]; for(let j=1;j<strs.length;j++){ if(i>=strs[j].length||strs[j][i]!==ch) return strs[0].slice(0,i); } } return strs[0]; }
TimeSpacePattern
O(n·m)O(1)String scan

33. Isomorphic Strings

Problem: True if characters map 1:1 between s and t.

Example: "egg","add" → true

Approach: Two maps (or map+set) for bijection.

🐍 Python

def is_isomorphic(s,t): if len(s)!=len(t): return False m1,m2={},{} for a,b in zip(s,t): if m1.get(a,b)!=b or m2.get(b,a)!=a: return False m1[a]=b; m2[b]=a return True

⚡ JavaScript

function isIsomorphic(s,t){ if(s.length!==t.length) return false; const m1=new Map(), m2=new Map(); for(let i=0;i<s.length;i++){ const a=s[i],b=t[i]; if((m1.has(a)&&m1.get(a)!==b)||(m2.has(b)&&m2.get(b)!==a)) return false; m1.set(a,b); m2.set(b,a); } return true; }
TimeSpacePattern
O(n)O(k)Hash map

34. First Unique Character

Problem: Index of first non-repeating char; else -1.

Example: "leetcode" → 0

Approach: Frequency count then second pass.

🐍 Python

from collections import Counter def first_uniq_char(s): c=Counter(s) for i,ch in enumerate(s): if c[ch]==1: return i return -1

⚡ JavaScript

function firstUniqChar(s){ const c=new Map(); for(const ch of s) c.set(ch,(c.get(ch)||0)+1); for(let i=0;i<s.length;i++) if(c.get(s[i])===1) return i; return -1; }
TimeSpacePattern
O(n)O(k)Frequency

35. Ransom Note

Problem: True if ransomNote can be built from magazine letters.

Example: "aa","aab" → true

Approach: Count magazine; decrement for note.

🐍 Python

from collections import Counter def can_construct(note,mag): return not (Counter(note)-Counter(mag))

⚡ JavaScript

function canConstruct(note,mag){ const c=new Map(); for(const ch of mag) c.set(ch,(c.get(ch)||0)+1); for(const ch of note){ if(!c.get(ch)) return false; c.set(ch,c.get(ch)-1); } return true; }
TimeSpacePattern
O(n+m)O(k)Frequency

38. Valid Perfect Square

Problem: True if num is a perfect square.

Example: 16 → true

Approach: Binary search; mid*mid == num.

🐍 Python

def is_perfect_square(num): lo,hi=1,num while lo<=hi: mid=(lo+hi)//2 sq=mid*mid if sq==num: return True if sq<num: lo=mid+1 else: hi=mid-1 return False

⚡ JavaScript

function isPerfectSquare(num){ let lo=1,hi=num; while(lo<=hi){ const mid=(lo+hi)>>1, sq=mid*mid; if(sq===num) return true; if(sq<num) lo=mid+1; else hi=mid-1; } return false; }
TimeSpacePattern
O(log n)O(1)Binary search

40. Pascal Triangle Row

Example: rowIndex=3 → [1,3,3,1]

Approach: Build row using C(n,k) ratios.

🐍 Python

def get_row(row_index): row=[1] for k in range(1,row_index+1): row.append(row[-1]*(row_index-k+1)//k) return row

⚡ JavaScript

function getRow(rowIndex){ const row=[1]; for(let k=1;k<=rowIndex;k++){ row.push(Math.floor(row[row.length-1]*(rowIndex-k+1)/k)); } return row; }
TimeSpacePattern
O(n)O(n)Combinatorics
