👨‍💻 9. AI Coding & AI Application Development

Step 9 of 12 — Use coding agents to ship faster, then own the app architecture: UI, API, and model boundary.

Two skills

  1. Build with AI: Cursor, Copilot, Claude Code, Codex — agents that edit repos.
  2. Build AI products: React/Next.js + FastAPI/Node that call models safely.

Production AI engineers need both. Agents do not replace code review, tests, or secret hygiene. Never paste production keys into a chat. Never merge agent diffs you did not read.

Cursor

AI-native editor: chat, inline edit, agent mode, rules, MCP. Best results come from a tight repo map, tests, and a short task. Point the agent at files. Ask for diffs, not essays. Keep secrets in env files that are gitignored.

Practice: "Add rate limiting to this FastAPI route and a pytest for 429" — then read every changed line.

Codex

OpenAI’s coding agent family (CLI/cloud/IDE depending on product generation). Treat it like a junior engineer with no production access: scoped tasks, CI as the judge, no unattended deploys. Good for greenfield spikes and test generation.

Claude Code

Terminal-first coding agent that can navigate a repo, run commands, and iterate. Powerful on large refactors. Constrain the workspace, review terminal commands (especially rm, migrate, push), and use CLAUDE.md / project instructions.

GitHub Copilot

Autocomplete + chat + agent features inside VS Code/GitHub. Strong for boilerplate and tests. Weaker if you accept every suggestion — Copilot does not know your SLA. Enable org policies for public code matching if required.

AI coding agents

Common loop: plan → edit → run tests → fix. Your job is the spec and the gates: lint, typecheck, unit tests, secret scan. Multi-file agents hallucinate APIs — keep OpenAPI and types as source of truth.

Dependency risk: Agents love to add packages. Review lockfiles. Pin versions. No mystery postinstall scripts.

React / Next.js

Default UI for AI apps: chat threads, tool call cards, citations, file upload. Use server routes or a BFF so the browser never sees model keys. Stream with SSE or fetch streams. Optimistic UI for user messages; show token/error states.

// Next.js route handler sketch export async function POST(req: Request) { const { messages } = await req.json(); const session = await getSession(); if (!session) return new Response("Unauthorized", { status: 401 }); const stream = await callModelGateway({ userId: session.id, messages }); return new Response(stream, { headers: { "Content-Type": "text/event-stream" } }); }

FastAPI

Python AI backend: Pydantic models, async, easy OpenAPI. Put RAG, agents, and eval jobs here. Split "HTTP API" from "workers" when jobs exceed request timeouts (ingest, fine-tune, batch eval).

from fastapi import FastAPI, Depends from fastapi.responses import StreamingResponse app = FastAPI() @app.post("/v1/chat") async def chat(body: ChatIn, user=Depends(auth)): return StreamingResponse(generate(user.id, body), media_type="text/event-stream")

Node.js

Use when the team is TS-first, or for MCP servers, Next.js API routes, and realtime (ws). Same gateway pattern: auth, quota, vendor SDK behind an adapter. Don’t run heavy embedding of 10k PDFs on the Node event loop — hand off to a Python/Go worker.
