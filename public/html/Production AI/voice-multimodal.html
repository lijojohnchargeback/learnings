🎙️ 8. Voice AI & Multimodal AI

Step 8 of 12 — Latency, turn-taking, and audio quality dominate. Text RAG rules still apply — with a 500ms budget.

Why voice is different

Chat can wait 3 seconds. Phone users hang up. Voice systems add speech-to-text, a brain (LLM/agent), text-to-speech, and a transport (WebRTC, SIP, WebSocket). Multimodal adds images/video in the same session. Production work is streaming, barge-in, and fallbacks when STT is wrong.

STT (speech-to-text)

Need partial transcripts for low latency and a final transcript for the LLM. Measure WER on your domain (names, SKUs). Send a hint / keyword list. Store audio (with consent) to debug STT vs model errors.

TTS (text-to-speech)

Stream audio chunks. Split on sentence boundaries so you can start speaking before the LLM finishes. SSML or vendor tags for pauses. Cache greetings. Match sample rate to the phone codec (often 8kHz μ-law on PSTN vs 24kHz on web).

ElevenLabs

High-quality voices, cloning (policy-sensitive), streaming TTS, and conversational products. Use for branded voice. Watch latency, concurrency limits, and consent for cloned voices. Keep a fallback TTS if the vendor blips.

OpenAI Realtime

Speech-to-speech (and audio+text) over a persistent connection. The model can interrupt and produce audio directly, cutting STT/TTS hops. You still need: session config, tools, truncation, and server-side secrets. Good for web voice UX; telephony still needs a SIP/WebRTC bridge.

Vapi

Voice agent platform: numbers, STT/TTS/LLM mix-and-match, tools via webhooks, squads. Fast to a demo phone number. Production: own the webhook SLA, log every turn, and pin model+voice versions.

Retell

Telephony-first voice agents (inbound/outbound). Similar job as Vapi: prompts, tools, call analytics. Compare on latency, telephony quality in your countries, and how custom LLM endpoints work.

Streaming

Pipeline: user audio → partial STT → (optional) endpointing → LLM token stream → sentence flush → TTS stream → speaker. Never wait for the full essay. Use a jitter buffer. Measure TTFB (time to first byte of audio).

Interruptions (barge-in)

If the user speaks, cancel TTS and optionally cancel the LLM. Voice activity detection (VAD) must ignore echo. Too sensitive = the bot never finishes; too dull = talking over the user. Tune on real calls. After barge-in, use the new transcript as the latest user turn.

Voice agents

Same agent rules, tighter constraints: short spoken sentences, confirm critical slots (phone numbers) by repeating them, DTMF for digits, and a "let me look that up" filler while tools run. Do not read JSON. Escalate to a human with a warm transfer and a written summary.

Multimodal: vision + voice (show a screenshot, talk through it). Keep one session clock. Images belong in tools/RAG, not as a 10MB base64 dump every turn.
