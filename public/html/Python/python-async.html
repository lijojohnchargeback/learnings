⚡ Python Async Programming

asyncio, async/await, and building high-performance backend services

📖 Why Async?

Async programming lets a single thread handle many I/O-bound operations concurrently — perfect for APIs, web scraping, and database-heavy backends.

ApproachBest ForConcurrency Model
SyncCPU-bound tasks, simple scriptsBlocking, one at a time
ThreadingI/O with blocking librariesOS threads (GIL limited)
MultiprocessingCPU-bound parallel workSeparate processes
Async (asyncio)I/O-bound, many connectionsSingle thread, event loop
💡 Rule of thumb: Use async for I/O-bound backend work (HTTP, DB, file I/O). Use multiprocessing for CPU-bound tasks.

🔑 async/await Syntax

import asyncio # Coroutine function — defined with async def async def fetch_data(url: str) -> dict: await asyncio.sleep(1) # Simulate network delay return {"url": url, "status": 200} # Calling a coroutine requires await (inside async function) # or asyncio.run() (top level) async def main(): result = await fetch_data("https://api.example.com") print(result) # Entry point asyncio.run(main())
⚠️ Common mistake: Calling fetch_data() without await returns a coroutine object, not the result. Always await or pass to asyncio.create_task().

🔄 asyncio Basics

import asyncio async def say_after(delay, message): await asyncio.sleep(delay) print(message) async def main(): print("Start") await say_after(1, "Hello") await say_after(1, "World") # Sequential: ~2 seconds total print("Done") asyncio.run(main())

📋 Tasks & Concurrent Execution

import asyncio async def fetch_user(user_id): await asyncio.sleep(0.5) return {"id": user_id, "name": f"User {user_id}"} async def main(): # Run concurrently with gather results = await asyncio.gather( fetch_user(1), fetch_user(2), fetch_user(3), ) print(results) # All 3 users in ~0.5s (not 1.5s) # Create tasks for more control task1 = asyncio.create_task(fetch_user(4)) task2 = asyncio.create_task(fetch_user(5)) user4 = await task1 user5 = await task2 asyncio.run(main())

⏱️ Timeouts & Cancellation

import asyncio async def slow_operation(): await asyncio.sleep(10) return "done" async def main(): try: result = await asyncio.wait_for(slow_operation(), timeout=2.0) except asyncio.TimeoutError: print("Operation timed out!") # Cancel a task task = asyncio.create_task(slow_operation()) await asyncio.sleep(0.1) task.cancel() try: await task except asyncio.CancelledError: print("Task was cancelled") asyncio.run(main())

🌐 HTTP with aiohttp

import aiohttp import asyncio async def fetch_url(session, url): async with session.get(url) as response: return await response.json() async def main(): urls = [ "https://api.github.com/users/octocat", "https://api.github.com/users/torvalds", ] async with aiohttp.ClientSession() as session: tasks = [fetch_url(session, url) for url in urls] results = await asyncio.gather(*tasks) for data in results: print(data["login"]) asyncio.run(main())
# FastAPI async endpoint from fastapi import FastAPI import httpx app = FastAPI() @app.get("/github/{username}") async def get_github_user(username: str): async with httpx.AsyncClient() as client: response = await client.get( f"https://api.github.com/users/{username}" ) return response.json()
