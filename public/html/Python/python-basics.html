📚 What is Python?

Python is a high-level, interpreted, general-purpose programming language known for its clean syntax, readability, and vast ecosystem. It is one of the most popular languages for backend development, data science, automation, and AI.

Key Facts

  • 📅 Created: 1991 by Guido van Rossum
  • 🐍 Name: Named after Monty Python's Flying Circus
  • 🌐 Use Cases: Web backends, APIs, scripting, data science, ML, DevOps
  • ⚡ Philosophy: "There should be one obvious way to do it" (Zen of Python)

Why Python for Backend?

Advantages ✅Considerations ⚠️
  • Easy to read and write
  • Huge ecosystem (PyPI)
  • Fast development speed
  • Great frameworks (Django, FastAPI, Flask)
  • Strong community support
  • Excellent for APIs and microservices
  • Slower than compiled languages (C, Go, Rust)
  • GIL limits true multi-threading for CPU tasks
  • Dynamic typing can hide bugs without tests

🔧 Setup & Installation

Install Python

# Check if Python is installed python --version python3 --version # Windows: Download from python.org # macOS: brew install python # Linux: sudo apt install python3 python3-pip python3-venv

Virtual Environment (Best Practice)

# Create virtual environment python -m venv venv # Activate (Windows) venv\Scripts\activate # Activate (macOS/Linux) source venv/bin/activate # Install packages pip install requests flask fastapi # Save dependencies pip freeze > requirements.txt
💡 Tip: Always use a virtual environment per project to isolate dependencies.

📦 Variables

Python uses dynamic typing — no need to declare variable types.

name = "Alice" # str age = 30 # int salary = 75000.50 # float is_active = True # bool # Multiple assignment x, y, z = 1, 2, 3 a = b = c = 0 # Naming conventions (PEP 8) user_name = "snake_case" # variables & functions MAX_RETRIES = 3 # constants (convention) class UserAccount: pass # PascalCase for classes
⚠️ Note: Python is case-sensitive. name and Name are different variables.

⚙️ Operators

Arithmetic

10 + 3 # 13 (addition) 10 - 3 # 7 (subtraction) 10 * 3 # 30 (multiplication) 10 / 3 # 3.333... (division, always float) 10 // 3 # 3 (floor division) 10 % 3 # 1 (modulus) 2 ** 10 # 1024 (exponent)

Comparison

5 == 5 # True 5 != 3 # True 5 > 3 # True 5 >= 5 # True

Logical

True and False # False True or False # True not True # False # Short-circuit evaluation name = None display = name or "Guest" # "Guest"

Walrus Operator (:=) — Python 3.8+

# Assign and use in one expression if (n := len(data)) > 10: print(f"List has {n} items")

🔀 Conditionals

age = 25 if age >= 18: print("Adult") elif age >= 13: print("Teenager") else: print("Child") # Ternary expression status = "adult" if age >= 18 else "minor" # Match statement (Python 3.10+) match status: case "adult": print("Welcome") case "minor": print("Restricted") case _: print("Unknown")

🔁 Loops

for Loop

# Iterate over a list fruits = ["apple", "banana", "cherry"] for fruit in fruits: print(fruit) # With index using enumerate for i, fruit in enumerate(fruits): print(f"{i}: {fruit}") # Range for i in range(5): # 0, 1, 2, 3, 4 print(i) for i in range(2, 10, 2): # 2, 4, 6, 8 print(i)

while Loop

count = 0 while count < 5: print(count) count += 1

break, continue, else

for num in range(10): if num == 3: continue # skip 3 if num == 7: break # stop at 7 print(num) else: print("Loop completed without break")

📋 List Comprehensions

# Basic squares = [x**2 for x in range(10)] # With condition evens = [x for x in range(20) if x % 2 == 0] # Dict comprehension word_lengths = {word: len(word) for word in ["hello", "world"]} # Set comprehension unique_lengths = {len(word) for word in ["hello", "world", "hi"]} # Generator expression (memory efficient) total = sum(x**2 for x in range(1000000))

✨ f-Strings (Formatted String Literals)

name = "Alice" age = 30 score = 95.567 # Basic print(f"Hello, {name}!") # Expressions inside print(f"Next year: {age + 1}") # Formatting numbers print(f"Score: {score:.1f}%") # Score: 95.6% print(f"ID: {42:05d}") # ID: 00042 # Debug (Python 3.8+) print(f"{name=}, {age=}") # name='Alice', age=30
