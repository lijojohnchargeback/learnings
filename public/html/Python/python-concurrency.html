🧵 Python Concurrency

Threading, multiprocessing, pools, and when to use each — beyond asyncio

🧭 Threads vs Processes vs Async

ToolBest forParallel CPU?
threadingI/O-bound, blocking libs❌ (GIL)
asyncioMany sockets / HTTP calls❌ (single thread)
multiprocessingCPU-bound Python✅
Process pool + asyncMixed I/O + CPU✅ for CPU part

If the library is blocking (e.g. classic requests, many DB drivers), use threads or run it in an executor from asyncio. If the work is pure Python math/loops, use processes.

🔒 GIL Recap

Only one thread executes Python bytecode at a time. During I/O waits (and in many C extensions), the GIL is released — so threads still overlap waiting time.

# I/O overlap works with threads import threading, urllib.request urls = ["https://example.com"] * 10 def fetch(url): with urllib.request.urlopen(url, timeout=10) as r: return len(r.read()) threads = [threading.Thread(target=fetch, args=(u,)) for u in urls] for t in threads: t.start() for t in threads: t.join()

🧵 threading Module

import threading import time def worker(name: str, delay: float) -> None: time.sleep(delay) print(f"{name} done") t = threading.Thread(target=worker, args=("A", 1.0), daemon=True) t.start() t.join(timeout=2) # Thread subclass class Job(threading.Thread): def __init__(self, n): super().__init__() self.n = n self.result = None def run(self): self.result = sum(range(self.n)) job = Job(1_000_000) job.start() job.join() print(job.result)

🔐 Locks & Thread Safety

Shared mutable state needs synchronization. Prefer queues over hand-rolled locks when possible.

import threading counter = 0 lock = threading.Lock() def inc(n): global counter for _ in range(n): with lock: counter += 1 threads = [threading.Thread(target=inc, args=(100_000,)) for _ in range(4)] for t in threads: t.start() for t in threads: t.join() print(counter) # 400000 # Other primitives: # threading.RLock() — re-entrant lock # threading.Event() — signal one-time/flag # threading.Condition() — wait/notify # threading.Semaphore(n) — limit concurrency # threading.local() — per-thread storage

🏊 ThreadPoolExecutor

from concurrent.futures import ThreadPoolExecutor, as_completed import urllib.request def fetch_len(url: str) -> int: with urllib.request.urlopen(url, timeout=10) as r: return len(r.read()) urls = ["https://example.com", "https://httpbin.org/get"] with ThreadPoolExecutor(max_workers=8) as pool: futures = {pool.submit(fetch_len, u): u for u in urls} for fut in as_completed(futures): print(futures[fut], fut.result()) # map preserves input order with ThreadPoolExecutor() as pool: lengths = list(pool.map(fetch_len, urls))

⚙️ multiprocessing

Each process has its own Python interpreter and GIL — true multi-core parallelism. Startup is heavier; arguments must be picklable.

from multiprocessing import Process, Queue def compute(n, out: Queue): out.put(sum(i * i for i in range(n))) if __name__ == "__main__": q = Queue() procs = [Process(target=compute, args=(5_000_000, q)) for _ in range(4)] for p in procs: p.start() for p in procs: p.join() print([q.get() for _ in procs])
⚠️ Windows: Guard entry points with if __name__ == "__main__": so child processes don’t re-import and spawn forever.

🏊 ProcessPoolExecutor

from concurrent.futures import ProcessPoolExecutor def cpu_heavy(n: int) -> int: return sum(i * i for i in range(n)) if __name__ == "__main__": data = [3_000_000, 3_000_000, 3_000_000, 3_000_000] with ProcessPoolExecutor() as pool: print(list(pool.map(cpu_heavy, data)))

🤝 Sharing State Between Processes

from multiprocessing import Process, Value, Array, Manager def bump(counter: Value): with counter.get_lock(): counter.value += 1 if __name__ == "__main__": counter = Value("i", 0) procs = [Process(target=bump, args=(counter,)) for _ in range(8)] for p in procs: p.start() for p in procs: p.join() print(counter.value) # Manager — flexible but slower (proxy objects over pipes) with Manager() as m: shared = m.dict(count=0) # pass shared to workers...

📬 Queues (Producer / Consumer)

from queue import Queue import threading q: Queue[str] = Queue(maxsize=100) def producer(): for i in range(20): q.put(f"job-{i}") q.put(None) # sentinel def consumer(): while True: item = q.get() if item is None: q.task_done() break print("processing", item) q.task_done() threading.Thread(target=producer).start() threading.Thread(target=consumer).start() q.join() # Cross-process: multiprocessing.Queue # Distributed: Redis / RabbitMQ / SQS for multi-machine workers
