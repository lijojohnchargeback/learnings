🔒 Virtual Environments

# Create venv python -m venv venv # Activate # Windows: venv\Scripts\activate # macOS/Linux: source venv/bin/activate # Deactivate deactivate # Verify you're in venv which python # Should point to venv/bin/python pip list # Shows only venv packages
💡 Always use venv: Never install project dependencies globally. Each project gets its own isolated environment.

📜 Poetry & pyproject.toml

# Install Poetry curl -sSL https://install.python-poetry.org | python3 - # Create new project poetry new my-api cd my-api # Add dependencies poetry add fastapi uvicorn sqlalchemy poetry add --group dev pytest black ruff mypy # Install all dependencies poetry install # Run commands in venv poetry run uvicorn app.main:app --reload poetry run pytest

🚀 Production Tips

  • Use Gunicorn + Uvicorn workers for production ASGI: gunicorn app.main:app -w 4 -k uvicorn.workers.UvicornWorker
  • Never run with --reload in production
  • Set DEBUG=false and use strong SECRET_KEY
  • Use a reverse proxy (Nginx) in front of your app
  • Enable HTTPS with Let's Encrypt
  • Set up structured logging (not print statements)
  • Use health check endpoints: GET /health
  • Configure connection pooling for databases
  • Use environment-specific config files
