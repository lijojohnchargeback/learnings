HyperText Markup Language - The Foundation of the Web

A) Introduction

What is HTML?

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It defines the structure and content of web documents.

Key Points:

  • HTML stands for HyperText Markup Language
  • It defines the structure of web content
  • HTML is the standard markup language for Web pages
  • Current major versions: HTML 4.01 and HTML 5.0

HTML 4.01

Released in 1999, older standard with limited multimedia support

HTML 5

Modern standard with native audio, video, graphics, and improved semantics

B) Basic HTML Structure

1. DOCTYPE Declaration

All HTML documents must start with a <!DOCTYPE> declaration. It informs the browser about the document type.

HTML5 DOCTYPE (Simple):

<!DOCTYPE html>

HTML 4.01 DOCTYPE (Complex):

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN" 
"http://www.w3.org/TR/html4/loose.dtd">
💡 Tip: The <!DOCTYPE> declaration is NOT case sensitive.

2. <html> - Root Element

The <html> tag defines an HTML document. It is the root element that contains all other HTML elements.

<html lang="en">
    <!-- All content goes here -->
</html>

3. <head> - Document Metadata

The <head> element contains metadata about the document. Metadata is not displayed on the page.

4. <title> - Page Title

The <title> tag defines the title of the document, shown in the browser's title bar or tab.

Importance for SEO:

  • Defines a title in the browser toolbar
  • Provides a title when added to favorites
  • Displays a title in search engine results

Best Practices:

  • ✓ Use longer, descriptive titles (avoid 1-2 word titles)
  • ✓ Keep titles under 50-60 characters
  • ✓ Make titles accurate and meaningful
  • ✗ Don't use just a list of words
  • ✗ Only one <title> element per document

5. <body> - Document Body

The <body> tag contains all visible content: headings, paragraphs, images, links, tables, lists, etc.

⚠️ Note: There can only be ONE <body> element in an HTML document.

J) Semantic Elements

A semantic element clearly describes its meaning to both the browser and the developer.

❌ Non-Semantic Elements

<div> and <span>

Tell nothing about their content

✅ Semantic Elements

<header>, <nav>, <article>

Clearly define their content

<details> Additional details (expandable)
<summary> Visible heading for <details>

K) Meta Tags

Meta Information Elements

Tag Description
<head> Contains document metadata
<meta> Defines metadata
<base> Base URL/target for relative URLs

Common Meta Tags

<head>
    <!-- Character encoding -->
    <meta charset="UTF-8">
    
    <!-- Viewport for responsive design -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    
    <!-- Description for SEO -->
    <meta name="description" content="Free Web tutorials">
    
    <!-- Keywords for SEO -->
    <meta name="keywords" content="HTML, CSS, JavaScript">
    
    <!-- Author information -->
    <meta name="author" content="John Doe">
    
    <!-- Auto-refresh page (rarely used) -->
    <meta http-equiv="refresh" content="30">
</head>

Meta Tag Attributes

charset

UTF-8 encoding includes millions of characters from all languages

<meta charset="UTF-8">

http-equiv

Provides HTTP header information (like refresh)

<meta http-equiv="refresh">

name & content

Specifies metadata name and its content

<meta name="description" content="...">

L) Logical vs Physical Tags

Bold vs Strong

<b> (Physical)

Bold text

Just makes text bold, no semantic meaning

<strong> (Logical)

Important text

Indicates importance, screen readers emphasize it

Italic vs Emphasis

<i> (Physical)

Italic text

Just makes text italic

<em> (Logical)

Emphasized text

Semantic emphasis, better for accessibility

💡 Best Practice: Use logical tags (<strong>, <em>) over physical tags (<b>, <i>) for better semantics and accessibility.

M) Conditional Comments (Deprecated)

Rarely used. These comments were specific to Internet Explorer:

<!--[if IE 9]>
    <p>You're using Internet Explorer 9</p>
<![endif]-->

<!--[if IE 8]>
    <p>You're using Internet Explorer 8</p>
<![endif]-->
⚠️ Note: Conditional comments are obsolete as Internet Explorer is discontinued. Modern browsers don't support this syntax.

N) HTML Entities

What are HTML Entities?

Reserved characters in HTML must be replaced with entities. Entities are used to display special characters that have special meaning in HTML or characters that aren't on your keyboard.

💡 Why? By default, HTML collapses multiple spaces into one space. To display multiple spaces or special characters, use entities.

O) HTML vs HTML5 Differences

Major Changes in HTML5

1. Removed Tags from HTML5

The following tags are NO LONGER supported in HTML5:

  • <frameset> - Use CSS grid/flexbox instead
  • <frame> - Use iframe or CSS
  • <noframe> - Obsolete
  • <big> - Use CSS font-size
  • <center> - Use CSS text-align
  • <dir> - Use <ul> instead
  • <basefont> - Use CSS

2. New Tags Added in HTML5

🎉 Multimedia Support:
  • <audio> - Native audio playback
  • <video> - Native video playback
  • <canvas> - Drawing graphics
  • <svg> - Vector graphics
📄 Semantic Elements:
  • <article>
  • <section>
  • <header>
  • <footer>
  • <nav>
  • <aside>
  • <main>

R) HTML Best Practices

✅ DO's

  • ✅ Always declare <!DOCTYPE html>
  • ✅ Use semantic HTML5 elements
  • ✅ Include proper meta tags (charset, viewport)
  • ✅ Use only one <h1> per page
  • ✅ Use <alt> attributes for images
  • ✅ Close all tags properly
  • ✅ Use lowercase for tag names
  • ✅ Quote attribute values
  • ✅ Validate your HTML
  • ✅ Use meaningful class and id names

❌ DON'Ts

  • ❌ Don't use deprecated tags (<font>, <center>, etc.)
  • ❌ Don't skip heading levels
  • ❌ Don't use inline styles excessively
  • ❌ Don't forget accessibility features
  • ❌ Don't use tables for layout
  • ❌ Don't use too many <div> elements
  • ❌ Don't forget to close tags
  • ❌ Don't mix upper and lowercase in tags

🎯 Performance Tips

  • 🚀 Place <script> tags at the bottom of <body>
  • 🚀 Use async or defer for external scripts
  • 🚀 Minimize DOM depth
  • 🚀 Optimize images (use appropriate formats and sizes)
  • 🚀 Use CDNs for common libraries
  • 🚀 Enable compression (gzip)
  • 🚀 Minimize HTTP requests

♿ Accessibility Tips

  • ♿ Use semantic HTML
  • ♿ Provide text alternatives for images
  • ♿ Ensure proper heading hierarchy
  • ♿ Use labels for form inputs
  • ♿ Provide skip navigation links
  • ♿ Ensure sufficient color contrast
  • ♿ Make interactive elements keyboard accessible
  • ♿ Use ARIA attributes when necessary
